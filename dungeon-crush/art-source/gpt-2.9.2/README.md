# 2.9.2 coherent locomotion sources

Four original OpenAI image_gen PNG outputs, one 4×2 eight-pose running atlas per class. Runtime files in art/motion292 use lossless WebP; decoded RGBA is identical and both file hashes are in generated-art-sources.json.

Each run uses a single atlas and a fixed frame-zero upper layer above the waist. Lower-body phases animate beneath that fixed layer. Source images are preserved unchanged; no detected face landmarks or per-frame automatic registrations are applied.

The previous mixed run and jump/dash intermediary atlases remain archived as source-only and are excluded from the APK. Dedicated jump poses use the original mobility first eight frames. Dash holds four chosen original mobility poses. Other combat clips retain their 24 authored cels. This supersedes earlier claims that the 2.9.1 source registration fixed observed body jitter.
