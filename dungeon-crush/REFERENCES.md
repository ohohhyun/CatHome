# 던전크러시 2.1 패치 참고자료

집사 사절의 app, tests, Gradle 설정과 빌드 워크플로는 변경하지 않는다.
이번 작업은 dungeon-crush와 전용 APK 워크플로만 변경한다.

## UI / 플레이 흐름

- 던파 공식 캐릭터 생성 가이드: https://www.dfoneople.com/gameinfo/guide/Getting-Started/Character-Creation
- 던파 공식 캐릭터 생성 UI 개편: https://www.dfoneople.com/news/updates/2560/System-Update/Character-Creation-UI
- 던파 공식 시스템 UI 개편: https://www.dfoneople.com/news/updates/1622/SYSTEM/UI-Renewal

참고한 패턴: 타이틀 시작, 별도 캐릭터 선택과 직업 정보, 마을 정비, 콘텐츠/지역/난이도 선택, 전투 HUD 스킬 슬롯, 결과 정산 후 마을 복귀.
공식 게임의 원본 UI 이미지·스프라이트·캐릭터·음원을 복제하지 않는다.
새 세계관·직업·몬스터·진행 시스템은 추가하지 않는다. 기존 4직업과 저장 데이터를 유지한다.

## 모션 / 이펙트

기존 fighters/enemies 텍스처를 팔·무기·상체·다리로 나누어 관절 회전한다.
대기/이동/공격/점프/회피/피격/다운을 상태 및 공격 타이머와 연결한다.
기존 스킬 종류에 맞춰 베기 궤적, 직선 빔, 범위 파동, 잔상, 타격 파편, 각성 컷인을 표시한다.
이는 기존 그림의 런타임 컷아웃 애니메이션이다. 상용 게임 수준의 수작업 프레임 스프라이트가 아니다.

## 사운드

기존 CC0 BGM/SFX를 고정 커밋에서 받아 Git blob SHA로 검증하고 APK 안에 포함한다.
출처와 저자는 app/src/main/assets/audio/CREDITS.txt, 파일별 출처는 audio-sources.json 참조.
재생 중 인터넷 다운로드는 없다. 타이틀 시작 터치로 음악을 활성화한다.
배경 음악과 효과음 볼륨, 화면 흔들림을 별도로 저장한다. 앱 백그라운드 진입 시 재생을 중지한다.


## 2.2 전투 아이콘과 가독성

스킬 아이콘은 Lorc / Game-icons.net의 기존 SVG 24개를 CC BY 3.0으로 사용합니다. 원본 커밋·경로·저자·변경 내역은 icon-sources.json, 앱 내 크레딧은 사운드 설정 하단과 icons/CREDITS.txt에 있습니다. 배경 패스를 제거하고 CSS로 색상/크기를 적용했습니다. 새 캐릭터 그림이나 세계관은 추가하지 않습니다.

기존 액션 RPG의 하단 단축 슬롯, 베기 궤적·총구 섬광·타격 파편·범위 예고·시전 바 관례를 적용합니다. HUD는 6칸 한 줄로 줄이며 사용 시에만 스킬명을 표시합니다. 몬스터 예고는 시전 지점에 고정하고 시전 바와 남은 시간을 함께 표시합니다.


## 2.3 원거리 전투

기존 원거리 액션 RPG의 발사체 비행·충돌, 전방 자동 조준, 원격 지점 폭발, 고정 예고와 비유도 마법탄 관례를 기존 세라/몬스터에 적용합니다. 새 직업·세계관·아트는 추가하지 않습니다. 투사체는 호스트가 판정하고 모든 LAN 기기에 같은 상태를 전송합니다.


## 2.4 마을과 포탈

기존 횡스크롤 RPG의 마을 이동 → 끝 포탈 → 콘텐츠/난이도 선택, 왼손 이동/오른손 액션 배치, 바닥과 원경의 속도가 다른 스크롤 관례를 적용합니다. 기존 마을/던전 배경과 캐릭터만 사용합니다. 포탈/회피/잠금 아이콘은 Lorc, 점프 아이콘은 Delapouite의 기존 Game-icons.net SVG(CC BY 3.0)입니다. 고정 원본 URL과 변경 내역은 icon-sources.json에 있습니다. 포탈 아트에 코드로 광원과 회전 효과를 합성하며 새 캐릭터·세계관을 만들지 않습니다.


## 2.5 중앙 시점과 이동 리듬

기존 횡스크롤 액션의 중앙 추적 카메라, 발 디딤/다리 회수, 짧은 회피 이동, 점프 착지 관례를 적용합니다. 기존 네 캐릭터 원화를 재사용하며 새 캐릭터/세계관/스킬은 추가하지 않습니다. 두 관절 계산으로 발 위치를 정하고 상체 기울기와 다리 회전을 분리합니다. 포탈의 입체 테두리·소용돌이·바닥 조명은 런타임 캔버스 렌더링이며 다른 게임의 포탈 이미지나 애니메이션을 복제하지 않습니다.


## 2.6 사용자 요청에 따른 GPT 이미지 생성

이 버전은 사용자가 명시적으로 GPT 그림을 새로 생성해 사용하도록 요청하여 생성 원화를 추가합니다. 기존 네 직업의 fighters.webp를 시각 참고로 사용한 4개 동작 PNG와 새 공격/광역/지원 이펙트 PNG 3개를 OpenAI image_gen으로 생성했습니다. 다른 게임의 원본 스프라이트나 이펙트를 복사하지 않습니다. 생성 원본은 보존하며, APK에는 동일한 PNG 바이트와 프레임 범위·발 기준선 메타데이터가 들어갑니다. 자세한 파일별 출처·해시는 generated-art-sources.json에 기록합니다. 플레이어는 전신 프레임을 직접 재생하며 기존 컷아웃 리그는 로드 전 대체 표시와 몬스터에 사용합니다.


## 2.7 연속 동작 / 타격 시점 / 개별 스킬

사용자의 추가 품질 개선 요청에 따라 네 직업의 8프레임 이동/점프, 3종 8프레임 기본 공격과 8프레임 시전, 24종 8프레임 스킬 이펙트를 image_gen으로 생성했습니다. 원본 PNG를 보존하고 무손실 WebP 인코딩의 디코딩 픽셀 동일성을 검사합니다. 발 기준선·시트별 크기·준비/타격/회복 시간을 연결하고, 짧은 입력 기억·회피 취소·접촉 프레임 정지·연속 밀려남을 적용합니다. 기존 게임 원본 스프라이트를 복제한 구현이나 던파와 동등한 품질을 검증한 결과는 아닙니다.
