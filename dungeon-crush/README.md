# 던전크러시! · DUNGEON CRUSH!

CatHome 저장소의 `dungeon-crush/`에 별도 Android 프로젝트로 보관하는 **영구 성장형 횡스크롤 액션 RPG**입니다. 원래 CatHome 앱과 루트 빌드 설정은 그대로 유지합니다. 마을에서 의뢰와 장비를 정비하고, 던전을 탐험해 전리품을 모으고, 새로운 지역과 직업 능력을 해금한 뒤 만렙 원정으로 이어집니다. 짧은 원정이 끝나도 캐릭터·장비·퀘스트·숙련 기록이 유지됩니다.

성장은 WebView 저장소와 Android SharedPreferences에 이중으로 보관하며 시작 시 더 최신 저장본을 선택합니다. 정산 원정 ID로 중복 보상을 막고, 구매·제작·분해·강화 후 즉시 저장합니다. 저장 공간이 부족해 양쪽 모두 저장에 실패하면 해당 거래를 되돌립니다. 캐릭터 4명의 장비·스킬·의뢰·기록은 개별적으로 유지합니다. 온라인 계정·기기 간 클라우드 동기화·경매장·거래 서버는 포함하지 않습니다.

기존 게임의 고유 캐릭터·맵·명칭을 복제하지 않은 독자 세계입니다. 캐릭터와 몬스터는 상태에 맞는 전신 스프라이트와 공격 이펙트로 표현하며, 던전은 공통 배경을 색조·지역 설정·전투 구성으로 구분합니다. 상용 게임의 방대한 아트·프레임별 전신 애니메이션·모든 시스템을 구현한 상태로 주장하지 않습니다.

`art-source/*.b64`의 아트·폰트는 Gradle 빌드가 자동 복원합니다. Gradle 8.9 / AGP 8.7.3 / SDK 35 / min SDK 23을 사용합니다. 수정 범위는 ohohhyun/CatHome뿐입니다.


2.1 UI 참고자료와 구현 범위는 [REFERENCES.md](REFERENCES.md), 기존 CC0 음원 출처는 [음원 크레딧](app/src/main/assets/audio/CREDITS.txt)과 [고정 파일 목록](audio-sources.json)에 정리했습니다. 새 캐릭터나 스토리는 추가하지 않습니다. 실제 BGM·효과음을 APK에 넣으며 별도 볼륨 설정과 백그라운드 중지를 제공합니다. Gradle 첫 빌드에는 Python 3와 음원 파일을 받기 위한 인터넷이 필요합니다. 포함 파일은 체크섬을 확인하므로 한 번 준비한 뒤에는 오프라인으로 재빌드할 수 있습니다.


2.2 전투 패치: 스킬 HUD를 6칸 한 줄로 줄이고 사용 시에만 스킬명을 표시합니다. 기본 아이콘 크기는 화면 높이에 따라 36~60px이며 640×296에서도 HUD 면적은 화면의 5.5% 이내입니다. Lorc의 기존 게임 아이콘 24개(CC BY 3.0, 출처·변경 내역은 icon-sources.json)를 포함했습니다. 이동 거리 기반 보행·무릎 관절·동작 블렌딩·무기 궤적·직업별 연출을 보완했습니다. 법사 몬스터 예고는 0.6→1.35초, 재시전 간격은 최소 3.4초이며 같은 대상의 동시 시전을 제한하고 공격으로 시전을 끊을 수 있습니다. 피해량·던전/파티 성장 시스템은 유지합니다.


2.3 원거리/회피 패치: 세라 기본 마탄 사거리는 450→1,100이며 실제 투사체가 날아가 적과 충돌할 때 피해를 줍니다. 관통 마탄은 최대 1,200, 폭발·균열은 최대 1,100 거리의 앞쪽 적 위치로 발사해 원거리에서 발동합니다. 균열 흡인은 원격 지점을 중심으로 적용하며, 연쇄 섬광·각성도 먼 적을 대상으로 합니다. 자동 조준은 바라보는 방향의 비슷한 높이에 있는 적을 우선합니다.

일반몹/중장갑/보스/법사의 기본 예고는 각각 1.0/1.25/1.5/1.65초이며, 보스 다중 범위 패턴은 1.7초입니다. 예고는 난이도로 단축되지 않습니다. 공격 후 별도 회복 시간을 두고 같은 대상에 공격 예고가 몰리는 것을 제한합니다. 법사는 예고 뒤 속도 160의 보이는 마법탄을 발사하며 발사 후에는 플레이어를 따라 꺾이지 않습니다. 시전 중 피격 취소도 유지합니다.

새 투사체 상태를 동기화하므로 LAN 파티는 모두 2.3으로 업데이트해야 합니다. 예전 클라이언트와는 게임 프로토콜을 구분해 보이지 않는 공격이 발생하는 혼용을 막습니다. 앱 ID·서명·기존 저장 형식은 유지합니다.


2.4 마을/조작 패치: 캐릭터를 선택하면 마을 입구에서 직접 걷기 시작합니다. 왼쪽 조이스틱으로 오른쪽 끝 원정 포탈까지 이동하고 포탈을 눌러 스토리/던전/레이드와 난이도를 선택한 뒤 입장합니다. 포탈 접근만으로 전투가 자동 시작되지는 않습니다. 퀘스트·장비·공방·Wi-Fi 파티는 마을 상단 메뉴에서 정비합니다.

왼손은 이동만 담당하고 점프·회피는 오른쪽 스킬 줄 위에 모았습니다. 게임 중 조작 버튼은 모두 기존 SVG 아이콘이며 글자/단축키는 표시하지 않습니다. 재사용 시간은 원형 음영으로 표시합니다. 이동과 점프/회피를 서로 다른 손가락으로 동시에 누를 수 있습니다. 마을과 전투는 같은 이동 처리를 사용하고 카메라가 첫 이동부터 따라갑니다. 바닥은 카메라와 같은 속도로, 원경은 28% 속도로 스크롤합니다. 포탈은 기존 Game-icons.net의 게이트 아트에 광원·회전 링·바닥 반사·입자를 겹쳐 표시합니다.


## 2.5 중앙 카메라 / 이동 / 포탈

- 마을과 던전 모두 캐릭터의 가로 위치를 화면 중앙(1600 기준 800)에 둡니다. 맵 입구·끝에서도 배경 여유 영역을 그려 조작 버튼에 가리지 않습니다. 배경 원경/바닥은 서로 다른 속도로 스크롤합니다.
- 직업별 이동 속도를 약 43% 올렸습니다(420 / 500 / 365 / 445). 빠른 출발·정지와 상하 이동 응답을 함께 개선했습니다. 몬스터 시전·투사체 속도는 올리지 않습니다.
- 회피는 0.22초 동안 연속 이동하며, 기존 무적 시간·재사용 대기시간을 유지합니다. 거리 기반 달리기, 발 디딤/다리 회수의 두 관절 계산, 상체·하체 분리, 점프 착지와 잔상 보간을 개선했습니다.
- 포탈은 기존 판타지 배경에 맞춘 분할 금속/석재 테두리, 안쪽 소용돌이, 빛 입자와 바닥 반사로 렌더링합니다. 조작 방식은 그대로 포탈 터치 후 목적지 선택입니다.
- 캐릭터 원화는 기존 네 장을 유지합니다. 상용 던파의 프레임별 원화/애니메이션과 동등한 수준을 구현한 것은 아닙니다.


## 2.6 GPT 생성 동작 / 공격 / 스킬 그림 · 이전 변경 기록

사용자의 새 이미지 생성 요청에 따라 OpenAI image_gen으로 기존 네 직업 외형을 참고한 동작 시트 4개와 이펙트 시트 3개를 만들었습니다. 캐릭터별 대기/달리기/기본 공격/스킬/점프 각 4프레임, 총 80프레임이며 공격/광역/보호막·회복 이펙트는 48프레임입니다. 파일 출처·원본 PNG 해시·격자·프레임 수는 generated-art-sources.json에 있습니다.

- 플레이어는 완성된 전신 그림을 상태에 맞춰 재생합니다. 달리기는 이동 거리, 공격·스킬은 실제 행동 타이머, 점프·착지는 기존 물리 상태를 따릅니다. 프레임 크기는 비율을 유지하고 발 기준선을 맞췄습니다.
- 공격 궤적, 광역 스킬, 타격, 마법탄, 보호막과 회복은 실제 생성된 그림을 사용합니다. 그림의 검정 배경은 screen 합성용이며 게임 화면에는 배경 사각형이 나타나지 않습니다. 적 시전 예고와 탄속은 기존과 같습니다.
- 프레임은 공격/스킬 종류에 맞춰 크기·위치·회전·단계를 조합합니다. 24개 스킬 각각에 별도의 전신 동작 시트가 있는 것은 아닙니다. 기존 4직업, 성장과 저장, 중앙 카메라, 이동 속도, Wi-Fi 파티는 유지합니다.
- 2.6 당시 원본 PNG 7개를 수정 없이 APK에 포함했으며 플레이 중 인터넷 연결이나 이미지 생성 호출은 없습니다. 생성 그림을 불러오기 전에는 기존 리그가 잠깐 대체 표시됩니다. 2.6 당시 몬스터 그림과 애니메이션은 기존 방식이었습니다.


## 2.7 동작 연결과 24종 스킬 연출 · 이전 변경 기록

- 네 직업 모두 달리기·점프 8프레임, 서로 다른 3단 기본 공격 각 8프레임, 시전 8프레임을 사용합니다. 기존 대기 4프레임을 포함해 실제 재생하는 전신 그림은 직업당 52장, 총 208장입니다. 새로 생성한 동작 원화는 192장입니다.
- 24개 스킬 각각 전용 8프레임 이펙트를 만들었습니다(총 192장). 준비 4단계 뒤 타격·발사 순간과 잔광 4단계를 연결합니다. 스킬의 전신 동작은 직업별 시전/콤보 클립을 조합하며, 모든 스킬에 독립적인 전신 시트가 있는 것은 아닙니다.
- 기본 공격은 직업별 3단 콤보로 이어집니다. 준비 동작 뒤 실제 타격/발사가 나가고, 근접 적중 시 짧은 프레임 정지·가벼운 전진·연속 밀려남을 표시합니다. 회복 직전 약 0.2초 입력 기억으로 짧게 누른 스킬도 이어서 나갑니다.
- 회피는 준비 중인 공격/스킬을 취소할 수 있습니다. 이미 소모한 MP와 재사용 시간은 돌아오지 않습니다. 돌진 스킬은 순간이동 대신 짧게 연속 이동합니다. 원거리 마법탄은 발사 이후 실제 비행·충돌을 따르며, 마도사 3타는 기존 강타 피해를 두 발로 나눠 냅니다.
- 협동에서는 화면용 동작 시간만 보간하며 서버의 피해·자원·입력 판정은 방장이 처리합니다. 새 준비/입력 상태가 추가되어 프로토콜을 5로 올렸습니다. 몬스터 시전 예고와 느린 투사체는 유지합니다.
- 생성 PNG 원본은 art-source/gpt-2.7에 보존했습니다. APK에는 디코딩 RGBA가 동일함을 확인한 무손실 WebP를 포함합니다. 대기 시트는 필요한 줄만 캐시하고 직업별 동작은 필요한 때 불러옵니다. 예전 공용 이펙트 3장은 원본을 보존하고 설치 파일에서는 제외합니다.
- 전체 흐름·24스킬·콤보를 자동으로 조작한 영상과 화면을 빌드 미리보기로 남깁니다. 실제 휴대폰의 체감 품질과 장시간 성능은 이 환경에서 직접 확인한 것이 아닙니다.

2.8에서는 대기 자세를 전투 시트의 가드 프레임과 공유합니다. 예전 생성 PNG 7개는 원본 보존용으로 남기고 APK에서 제외합니다. 신규 몬스터·장비 이미지 원본은 `art-source/gpt-2.8/`, 기존 동작·스킬 원본은 `art-source/gpt-2.7/`에 보관합니다.
