# 던전크러시! · DUNGEON CRUSH!

CatHome 저장소의 `dungeon-crush/`에 별도 Android 프로젝트로 보관하는 **영구 성장형 횡스크롤 액션 RPG**입니다. 원래 CatHome 앱과 루트 빌드 설정은 그대로 유지합니다. 마을에서 의뢰와 장비를 정비하고, 던전을 탐험해 전리품을 모으고, 새로운 지역과 직업 능력을 해금한 뒤 만렙 원정으로 이어집니다. 짧은 원정이 끝나도 캐릭터·장비·퀘스트·숙련 기록이 유지됩니다.

## 별도로 설치하는 APK · 기존 게임 유지

**던전크러시!은 별도 앱 `com.dungeoncrush.game`입니다. ‘집사 사절!’의 `com.cathome.game`을 대체하지 않습니다.** 두 게임을 함께 설치할 수 있습니다. 이번 패치는 전용 브랜치의 던전크러시 파일과 전용 빌드/배포 워크플로에만 적용했습니다. 기존 게임의 원본 앱·루트 빌드·복구 APK는 변경하지 않습니다.

[던전크러시 2.9 APK 직접 다운로드](https://github.com/ohohhyun/CatHome/releases/download/dungeon-crush-v2.9/DungeonCrush-2.9.apk) · [전투·모션 비교 영상과 릴리스](https://github.com/ohohhyun/CatHome/releases/tag/dungeon-crush-v2.9). APK 파일을 눌러 설치하며 압축을 풀 필요가 없습니다. 친구에게 다운로드 링크를 공유할 수 있습니다. 영상은 브라우저에서 자동 조작한 게임 화면입니다.

새 게임 versionCode 20 / versionName 2.9-motion-overhaul. 기존 2.8과 같은 서명·앱 ID·프로토콜 6·저장 형식을 유지합니다. 같은 화면을 보려면 파티원 모두 2.9로 업데이트를 권장합니다. 이번 전용 워크플로는 던전크러시만 빌드합니다. 집사 사절 코드·빌드·복구 APK는 수정하거나 빌드하지 않습니다. 예전 공유 ID APK는 배포 대상이 아닙니다.

Android 6.0 이상과 최신 Android System WebView를 권장합니다. GitHub Artifact 다운로드에는 로그인이 필요하며 파일 앱의 ‘알 수 없는 앱 설치’ 허용이 필요할 수 있습니다. 테스트 서명 APK이며 Play 스토어용 서명은 아닙니다.

## 2.9 그래픽·24단계 모션

- 직업 4종의 달리기·점프·회피·기본 3연타·시전은 주요 동작별 24개 그림을 시간순으로 재생합니다. 대기·피격·착지·쓰러짐을 포함해 캐릭터 자세는 704개입니다. 24 FPS로 고정하는 뜻은 아니며 화면은 requestAnimationFrame으로 그립니다.
- 몬스터 4종의 이동과 공격도 각각 24개 그림, 총 192개 자세를 사용합니다. 예고 종료에 공격의 접촉 자세를 맞추며 시전 시간·탄속·피해 판정은 유지합니다.
- 스킬 아이콘 24개를 채색한 그림으로 교체했습니다. 기존 SVG는 로딩 전 대체 표시로 유지하며 버튼의 접근성 이름도 유지합니다. 직업별 각성 이펙트 32개 그림, 무기·주먹·탄두 궤적과 지면 조명을 추가했습니다.
- 새 원본 PNG 아틀라스 101개를 `art-source/gpt-2.9/`에 보존하고, 검증한 WebP를 오프라인 APK에 포함합니다. 원본·설치 파일 이미지 해시는 `generated-art-sources.json`에 기록합니다.
- 필요한 동작을 먼저 불러오며 동시 이미지 디코딩 2개, 화면용 자르기와 128 MiB 목표 LRU 캐시를 사용합니다. 전체 그림을 한꺼번에 읽는 검증 모드는 별도입니다.

## 2.8 전투·파티 수정 · 이전 변경 기록

- 몬스터 처치 경험치를 파티 전원에게 지급하고 매번 저장합니다. 중간 이탈·연결 종료 전에 받은 경험치는 유지하며 반복 상태 패킷과 종료 보상에서 중복 지급하지 않습니다. 전투 중 EXP 게이지와 60레벨 이후 숙련 진행도도 표시합니다.
- 피해 숫자는 본인이 가한 공격만 표시합니다. 본인이 받은 피해와 회복량은 유지하며 동료의 공격 이펙트는 함께 보입니다.
- HP 숫자를 게이지 밖의 고대비 표시로 옮겼습니다. 물약·점프·회피는 오른쪽 스킬 옆에서 이동과 동시에 사용할 수 있습니다.
- 던전 물약은 최대 HP의 50% 회복, 재사용 180초입니다. 최대 체력 초과·사망 상태 사용·쿨타임 우회·짧은 파티 입력 누락을 방지합니다. 키보드 H로도 사용합니다.
- 가방·착용 슬롯·장비 상세·공방 강화·제작·재료·물약에 GPT로 만든 장비 및 자원 아이콘 30종을 적용했습니다.
- 몬스터 4종의 8프레임 이동과 8프레임 공격을 추가했습니다. 공격 준비와 타격은 기존의 느린 예고 시간에 맞춥니다. 파티에서 캐릭터·몬스터 움직임을 시간과 이동 속도에 맞춰 보간합니다.
- 총구 앞을 지나친 근거리 판정을 보완하고 적 움직임에 대한 제한적인 조준 보정을 추가했습니다. 탄두 표시를 판정 위치에 맞추며 총구에서 적 몸통까지 높이를 연결합니다.
- 전투에 쓰던 UI 스위치 소리를 제거하고 CC0 칼날·금속·주먹·천 움직임 등 전투 음원 14개를 추가했습니다. 직업·공격별 소리와 겹침·거리별 음량을 조정했습니다.

## 계속 이어지는 플레이

1. **타이틀 → 게임 시작 → 캐릭터 선택 → 마을 → 스토리/던전/레이드 선택**: 별도 화면에서 캐릭터와 지역·난이도를 확인한 뒤 입장합니다. **마을 · 재의 항구**: 원정대 의뢰, 원정 지도, 장비 가방, 전직·스킬, 제작·강화에 접근합니다.
2. **메인 의뢰와 지역 해금**: 8개 지역의 던전 24개를 순서대로 정복하고 보상을 보고해 다음 목적지를 엽니다. 의뢰 보상은 중복 수령할 수 없습니다.
3. **던전 탐색**: 일반 던전은 5개 방입니다. 각 방의 적을 정리하고 오른쪽 관문으로 직접 이동합니다. 마지막 방의 보스를 처치하면 정산합니다.
4. **장비 파밍과 빌드**: 직업별 장비를 모으고 착용·강화·분해·제작하며 스킬 포인트를 배분합니다. 같은 던전을 다시 돌아 재료와 더 좋은 장비를 얻을 수 있습니다.
5. **전직과 각성**: 20레벨·메인 의뢰 8개 완료로 전직, 45레벨·전직·메인 의뢰 17개 완료로 각성합니다. 직업명, 스킬, 포인트가 바뀝니다.
6. **60레벨 이후**: 메인 의뢰 24개를 마치면 균열·심연·보스 5연전이 열립니다. 최대 레벨에서도 경험치로 숙련을 계속 높이고, 에픽 세트와 높은 균열 기록을 노립니다.

입장 횟수나 피로도 제한이 없습니다. 일일 의뢰는 추가 보상이며 일반 플레이를 막지 않습니다. 원정에서 실패해도 기존 캐릭터 성장과 장비가 초기화되지 않습니다.

## 같은 Wi-Fi 협동

모두 같은 Wi-Fi와 같은 2.8 APK를 사용하세요. 각자 캐릭터를 선택한 뒤 한 명이 **Wi-Fi 협동 → 방 만들기**로 표시된 IP·4자리 코드를 알려주고, 나머지가 입력해 참가합니다. 최대 4명, PC·계정·외부 게임 서버 없이 동작합니다.

파티원 모두가 목적지의 퀘스트·레벨·가방·입장 재료 조건을 충족해야 합니다. 전투 후 **마을로 돌아가기**로 파티를 유지하며 각자 장비와 퀘스트를 정비하고 다음 원정을 시작할 수 있습니다. 방장만 목적지·시작·일시정지·재도전을 조절합니다. 진행 중인 원정에는 새로 합류할 수 없습니다.

게스트 Wi-Fi나 AP 격리 환경에서는 연결되지 않을 수 있습니다. 방장 앱을 닫거나 백그라운드로 보내면 방이 종료됩니다. VPN이 있으면 표시된 방장 IP를 Wi-Fi 상세 정보와 비교하세요. 이전 1.0 클라이언트와는 호환되지 않습니다.

## 저장과 구성

게임·아트·한글 폰트를 APK에 포함합니다. 게임은 Canvas/WebView, LAN은 Java TCP 포트 47655를 사용합니다. 외부 웹사이트를 불러오는 방식이 아닙니다. 로그인·광고·과금·CDN 요청이 없습니다.

성장은 WebView 저장소와 Android SharedPreferences에 이중으로 보관하며 시작 시 더 최신 저장본을 선택합니다. 정산 원정 ID로 중복 보상을 막고, 구매·제작·분해·강화 후 즉시 저장합니다. 저장 공간이 부족해 양쪽 모두 저장에 실패하면 해당 거래를 되돌립니다. 캐릭터 4명의 장비·스킬·의뢰·기록은 개별적으로 유지합니다. 온라인 계정·기기 간 클라우드 동기화·경매장·거래 서버는 포함하지 않습니다.

왼손은 이동만 담당하고 점프·회피는 오른쪽 스킬 줄 위에 모았습니다. 게임 중 조작 버튼은 모두 기존 SVG 아이콘이며 글자/단축키는 표시하지 않습니다. 재사용 시간은 원형 음영으로 표시합니다. 이동과 점프/회피를 서로 다른 손가락으로 동시에 누를 수 있습니다. 마을과 전투는 같은 이동 처리를 사용하고 카메라가 첫 이동부터 따라갑니다. 바닥은 카메라와 같은 속도로, 원경은 28% 속도로 스크롤합니다. 포탈은 기존 Game-icons.net의 게이트 아트에 광원·회전 링·바닥 반사·입자를 겹쳐 표시합니다.


## 2.5 중앙 카메라 / 이동 / 포탈

- 마을과 던전 모두 캐릭터의 가로 위치를 화면 중앙(1600 기준 800)에 둡니다. 맵 입구·끝에서도 배경 여유 영역을 그려 조작 버튼에 가리지 않습니다. 배경 원경/바닥은 서로 다른 속도로 스크롤합니다.
- 직업별 이동 속도를 약 43% 올렸습니다(420 / 500 / 365 / 445). 빠른 출발·정지와 상하 이동 응답을 함께 개선했습니다. 몬스터 시전·투사체 속도는 올리지 않습니다.
- 회피는 0.22초 동안 연속 이동하며, 기존 무적 시간·재사용 대기시간을 유지합니다. 거리 기반 달리기, 발 디딤/다리 회수의 두 관절 계산, 상체·하체 분리, 점프 착지와 잔상 보간을 개선했습니다.
- 포탈은 기존 판타지 배경에 맞춘 분할 금속/석재 테두리, 안쪽 소용돌이, 빛 입자와 바닥 반사로 렌더링합니다. 조작 방식은 그대로 포탈 터치 후 목적지 선택입니다.
- 캐릭터 원화는 기존 네 장을 유지합니다. 상용 던파의 프레임별 원화/애니메이션과 동등한 수준을 구현한 것은 아닙니다.


## 2.6 GPT 생성 동작 / 공격 / 스킬 그림 · 이전 변경 기록

사용자의 새 이미지 생성 요청에 따라 OpenAI image_gen으로 기존 네 직업 외형을 참고한 동작 시트 4개와 이펙트 시트 3개를 만들었습니다. 캐릭터별 대기/달리기/기본 공격/스킬/점프 각 4프레임, 총 80프레임이며 공격/광역/보호막·회복 이펙트는 48프레임입니다. 파일 출처·원본 PNG 해시·격자·프레임 수는 generated-art-sources.json에 있습니다.

- 플레이어는 완성된 전신 그림을 상태에 맞춰 재생합니다. 달리기는 이동 거리, 공격·스킬은 실제 행동 타이머, 점프·착지는 기존 물리 상태를 따릅니다. 프레임 크기는 비율을 유지하고 발 기준선을 맞췄습니다.
- 공격 궤적, 광역 스킬, 타격, 마법탄, 보호막과 회복은 실제 생성된 그림을 사용합니다. 그림의 검정 배경은 screen 합성용이며 게임 화면에는 배경 사각형이 나타나지 않습니다. 적 시전 예고와 탄속은 기존과 같습니다.
- 프레임은 공격/스킬 종류에 맞춰 크기·위치·회전·단계를 조합합니다. 24개 스킬 각각에 별도의 전신 동작 시트가 있는 것은 아닙니다. 기존 4직업, 성장과 저장, 중앙 카메라, 이동 속도, Wi-Fi 파티는 유지합니다.
- 2.6 당시 원본 PNG 7개를 수정 없이 APK에 포함했으며 플레이 중 인터넷 연결이나 이미지 생성 호출은 없습니다. 생성 그림을 불러오기 전에는 기존 리그가 잠깐 대체 표시됩니다. 2.6 당시 몬스터 그림과 애니메이션은 기존 방식이었습니다.


## 2.7 동작 연결과 24종 스킬 연출 · 이전 변경 기록

- 네 직업 모두 달리기·점프 8프레임, 서로 다른 3단 기본 공격 각 8프레임, 시전 8프레임을 사용합니다. 기존 대기 4프레임을 포함해 실제 재생하는 전신 그림은 직업당 52장, 총 208장입니다. 새로 생성한 동작 원화는 192장입니다.
