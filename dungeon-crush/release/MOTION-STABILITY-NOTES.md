# 2.15.1 이동 떨림·전신 잔상 수정

[가시 늑대 수정 전후](MotionStability-2.15.1-Comparison.png) · [같은 추적 상황의 재생 영상](MotionStability-2.15.1-Comparison.webm) · [간소화한 미리보기](SimplePreview-2.15.1.png)

## 확인한 원인과 수정

- 안개 사냥터의 녹색 적은 `thornwolf`(가시 늑대, skin 5)입니다. X가 플레이어와 거의 같고 Y만 맞추는 추적 상황을 재현했습니다. 기존의 축별 `sign(distance) * speed * dt` 이동은 X의 남은 거리보다 큰 보폭으로 좌우를 왕복했습니다. 60Hz·180틱 재현에서 방향 반전이 43회 발생했고 수정 후 0회입니다. 각 축 이동량을 실제 남은 거리로 제한하고, X 차이 0.5 이내에서는 방향을 유지합니다. 이동 속도·공격 예고·피해 수치는 유지합니다.
- 걷기/달리기와 대기 원화의 프레임별 기준점 차이로 몸 전체가 튀는 현상을 보정했습니다. 6직업·30외형·92몬스터, 이동 128개와 캐릭터 대기 36개 은행의 1,424개 포즈를 조사했습니다. `authoredPivots`에 이전 기준점을 보관하고, 상체 쪽 불투명 실루엣의 주기적 위치 변동을 5탭 필터로 줄입니다. 첫 포즈의 기존 기준점, 원화 픽셀, 프레임 수, 몸 비율·배율은 보존합니다. 공격·점프의 의도된 동작을 이 필터로 평탄화하지 않습니다.
- 기본 캐릭터의 공격과 외형의 공격·점프·회피에서 두 전신 그림을 투명하게 합성하던 crossfade를 제거했습니다. 한 시점에는 원화 포즈 하나를 불투명하게 그립니다. 스킬 효과와 투사체의 의도된 빛 효과는 유지합니다.
- 로컬 몬스터에도 물리 틱 사이의 표시 시간과 위치를 적용합니다. 같은 렌더 프레임에 카메라·펫·캐릭터가 좌표를 여러 번 조회해도 표시 보간을 한 번만 수행합니다. 표시 코드는 전투 상태를 수정하지 않습니다.

수치 자료는 `art-source/locomotion-stability-review.json`, 재생성 도구는 `tools/stabilize-locomotion.py`입니다. 원화 SHA-256에 검수를 묶었습니다. 실루엣 위치 가속도는 위치 떨림의 대용 지표이며 실제 단말 FPS나 모든 관절의 자연스러움을 측정한 수치가 아닙니다.

## 상점 미리보기

- 상단은 **원화 / 미리보기** 두 항목입니다. 동작 선택창·스킬 선택창·방향·확대 조작과 별도 스킬 효과 탭을 제거했습니다.
- 선택한 외형을 입은 캐릭터가 대기→걷기→달리기→연속 공격→점프→기본 스킬 한 개를 약 12초마다 반복합니다. 미리보기 도중 다른 외형을 선택하면 그 외형으로 처음부터 재생하며 화면을 유지합니다.
- 미리보기는 독립 전투 상태를 사용합니다. 실제 캐릭터의 장비·보유권·스킬·골드·성장 기록을 변경하지 않습니다. 실제 장착과 해제는 기존 버튼을 사용합니다.

## 검증 범위와 배포 기준

- 신규 코드 검사: 164개 은행의 기준점·원화 해시·첫 포즈 보존, 몬스터 92종×양방향×30/60/120Hz×추적 두 경우 = 1,104개 회귀 사례, 축별 초과 이동·방향 떨림·LAN 직렬화 결정성을 확인합니다.
- 신규 Chromium 검사: 실제 전투의 가시 늑대 추적, 기본 6직업·30외형·92몬스터의 양방향 이동/공격 30,720개 렌더 표본에서 누락 없이 전신을 한 번만 불투명하게 그리는지 확인합니다. 몬스터 12개 비교 시트와 전투 화면을 저장합니다.
- 기존 전체 검사로 744개 기본 캐릭터 포즈, 1,984개 몬스터 포즈, 1,680개 외형 포즈, 점프/회피/3단 공격/9스킬, 실장착·해제·마을/전투 재진입, 크기·잘림, UI·저장·통신·사운드를 다시 확인합니다.
- 전체 57개 검사(코드 26 + Java 2 + Chrome 29), APK/AAB·Android lint·기존 서명·최종 포함 리소스가 모두 통과한 소스만 APK로 제공합니다. 실패 또는 실행 중인 검사는 완료로 표기하지 않습니다.
- 설치 버전은 2.15.1 / versionCode 43입니다. 저장 형식 2와 Wi-Fi 프로토콜 10을 유지합니다. APK는 기존 테스트 서명을 유지하며 기존 앱을 삭제하지 않고 업데이트합니다.
- 실제 Android 단말의 장시간 FPS·발열·조작감, 시스템 WebView별 표시와 2~4대 Wi-Fi 실측은 여전히 별도 검수입니다. 서버/DB·실결제는 연결하지 않습니다. 집사 사절 원본 및 루트 앱은 수정하지 않습니다.
