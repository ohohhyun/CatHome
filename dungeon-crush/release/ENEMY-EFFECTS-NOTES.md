# 2.18.0 몬스터 스킬 이펙트 개선

몬스터의 기존 원화·이동 모션, 공격 시간·범위·피해·경직·경험치·장비·보상은 유지합니다. 저장 형식2 / Wi-Fi 프로토콜11 / 기존 설치 서명을 유지하며 앱 버전은2.18.0, 설치 버전47입니다. 집사 사절 원본과 서버·DB·실결제는 수정하지 않습니다.

## 변경

- 16개 속성을 재질과 실루엣으로 구분합니다. 수호 참격의 겹친 검기, 용광로의 균열·파편, 입체적인 가시와 공허 촉수, 면이 나뉜 수정·얼음, 포말을 가진 물결, 분기 낙뢰, 시계·태엽, 월식 고리, 용암 화염, 유성 잔류 궤적, 포자 안개, 여명 광주를 적용했습니다.
- 공통 원형 준비 표시를 발밑 문양·응집 입자·발사 지점의 속성 광원으로 교체했습니다. 표시 위치는 보간된 몬스터 좌표를 사용해 몸과 분리되어 떨리지 않도록 합니다.
- 투사체 머리·꼬리의 방향을 구분하고, 적 투사체의 타격에서 누락됐던 enemy/vfx/source/높이 메타데이터를 전달합니다. 피격 이펙트가 기본 플레이어 효과로 바뀌던 문제를 수정했습니다. 피해 계산은 바꾸지 않습니다.
- 공격 범위의 어두운 외곽선과 색상 경계를 모든 외형에서 마지막에 다시 그립니다. 원형·도넛·직선 경고는 기존 충돌 계산과 같은 좌표/레인 비율을 사용합니다. 도넛 중심에는 타격 장식을 그리지 않으며 중앙 안전 표시는 유지합니다.
- 결정적인 절차 텍스처 48개까지 캐시합니다. 16속성의 전체 텍스처 픽셀은6,291,456 bytes로 제한되며 매 프레임 이미지 파일을 새로 요청하지 않습니다. 장식용 그리기는 프레임당96개, 효과 줄이기에서는24개까지 허용합니다. 핵심 타격 형태·투사체·경고는 장식 예산 소진으로 생략하지 않습니다. 기존 공통 입자와 광원을 중복 생성하지 않습니다.
- 효과 줄이기는 불필요한 번짐·궤적·거품을 줄이고 핵심 실루엣과 회피 경계를 보존합니다. 전체 화면 섬광을 추가하지 않습니다.

- `enemy-effects.test.cjs`: 2.17 엔진 고정본과 92종×3공격 단계×싱글/4인 조건 552개 사례를 동일 입력으로 비교합니다. 이펙트 이외의 게임 상태가 완전히 같은지 검사합니다. 16속성 투사체의 피해·타격 정보와 사망 시 시전 취소, 원형/도넛/직선 경고-판정 일치도 검사합니다.
- `enemy-effects-presentation.test.cjs`: 92종의 시전/타격/잔류/효과 줄이기 368개 화면, 16속성×4단계×2모드, 실제 픽셀로 확인한 도넛 안전지대·직선 경계, 캔버스 상태 복원, 캐시/장식 예산, 실제 브라우저 4인 전투의 시전→타격과 1280/740/640 화면을 검사합니다. 스크린샷·영상·수치는 CI artifact에 남깁니다.
- 기존 성장·스킬·UI·모션·랭킹·주간/2주 정산·통신 검사를 합쳐 전체65개(코드30 + Java2 + Chrome33) 통과 후 APK/AAB·Android lint·기존 서명·포함 파일과 공개 전체 다운로드를 검증합니다.
- 브라우저에서 측정한 그리기 시간은 회귀 자료이며 실기기 FPS/발열로 표현하지 않습니다. 실제 Android 업데이트 설치·장시간 FPS/발열·터치 조작·2~4대 물리 Wi-Fi 기기는 별도입니다.
