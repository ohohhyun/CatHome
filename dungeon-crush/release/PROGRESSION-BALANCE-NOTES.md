# 2.17.0 성장·전투·반복 파밍·스킬 습득 수정

현재 만렙은 100입니다. 60레벨부터 열리는 원정을 ‘만렙 콘텐츠’로 표시하던 문구를 고난도 원정으로 고치고, 선택 화면에 현재 레벨/100을 표시했습니다. 기존 XP 곡선과 저장된 XP·레벨·장비·스킬 랭크를 보존합니다. 앞으로 얻는 경험치와 PvE 전투 계산만 조정합니다.

## 원인과 수정

- 메인 퀘스트 보상이 다음 지역 요구 레벨까지의 XP 차이 전체를 채웠습니다. 이를 25%로 줄였고 클리어 XP는 `(160+지역레벨×32)×난이도 배율`, 처치 XP는 기존의 약 65%로 조정했습니다. 기존 레벨을 내려서 속도를 늦추지 않습니다. 다음 지역이 열려도 레벨·장비를 갖추도록 현재 지역을 반복할 수 있습니다.
- 레벨당 자동 공격력 증가를 0.055→0.018, HP 증가를 18→12로 조정했습니다. 장비의 공격/방어와 강화, 스킬 랭크가 더 큰 차이를 만듭니다. PvP의 기존 30레벨/능력치 보정은 유지합니다.
- 일반 몬스터/보스 HP와 중후반 공격력을 조정했습니다. 기본 공격의 반복 경직에는 재적용 간격을 넣어 몬스터가 반격하도록 했습니다. 경고 시간·회피 무적·위험 구역의 회피 가능성은 유지했습니다. 방마다 무료로 HP를 거의 절반까지 회복하던 구조도 낮췄습니다.
- 균열·심연·원정은 모든 장비 부위가 나오는 기존 구조를 유지합니다. 스토리 지역의 첫 던전은 무기/신발, 두 번째는 상의/하의, 세 번째는 목걸이/반지로 드롭 부위를 구분합니다. 일반/모험/왕의 길/악몽의 최소 장비 등급은 일반/마법/희귀/유니크입니다. 같은 던전·난이도를 3회 완료할 때마다 추가 철편·가루를 지급하며 선택 화면에 보상과 진행도를 표시합니다. 중복 정산은 재료를 다시 주지 않습니다.
- 기존에는 SP를 다른 스킬에 먼저 쓰면 해금 레벨에 도달해도 새 스킬을 못 배웠습니다. 첫 습득은 무료, 랭크 2~10 강화에만 SP를 사용하도록 분리했습니다. 기존 랭크를 삭제하지 않으며 첫 습득에 사용한 SP가 다시 가용 포인트에 반영됩니다. 레벨/전직/각성/SP 부족 이유를 구분해서 보여 줍니다. 빈 슬롯이 있으면 새 스킬을 장착하되 이미 꽉 찬 사용자 배치는 덮어쓰지 않습니다.
- 프리스트 회복/방어막과 다른 직업 방어막 등 일부 지원 스킬은 랭크를 올려도 효과가 고정됐습니다. PvE에서 랭크에 따라 효과·지속 시간이 성장하도록 수정했고 실제 효과량을 표시합니다. PvP의 보정 비율은 유지합니다.
- 짧은 스킬 터치가 두 시뮬레이션 프레임 사이에서 사라질 수 있었습니다. 최초 터치를 최대 700ms 동안 보존해 기본 공격을 누른 상태에서도 현재 공격의 정상 취소 시점에 한 번 발동시키고 소비합니다. 기본 공격을 누르거나 화면/상태가 바뀌면 취소해 이전 스킬이 기본 공격을 덮지 않도록 했습니다.

## 검수 범위

`progression-balance.test.cjs`는 2.16 저장·1~100레벨 XP 곡선 보존, 6직업×8스킬의 SP 0 첫 습득, 강화 SP/수련 조건, 처치/클리어/퀘스트 경험치 속도, 부위/난이도 보상, 반복 재료와 정산 중복, 지원 스킬 랭크 효과와 PvP 보정을 확인합니다. 같은 입력 정책으로 초반 6직업의 첫 던전과 60레벨 초급 장비/기본 공격, 일반 장비·랭크1 대 +6 강화·랭크5 악몽 던전 완주를 비교합니다. 이 봇 결과는 제한된 입력 정책의 회귀 자료이며 모든 사람의 난이도 체감이나 실기기 조작 검수를 대신하지 않습니다.

`progression-presentation.test.cjs`는 48개 실제 습득/장착, SP 부족·전직/각성 안내와 실제 수련, 저장 실패 롤백, 재시작 후 보존, 3개 화면의 목표 파밍/3회 진행 표시, 만렙100 표시, 배운 스킬의 실제 짧은 터치 발동을 확인합니다. 기존 검사를 합친 63개를 통과한 뒤 APK/AAB·Android lint·기존 설치 서명·포함 파일을 검증하고 공개 APK의 익명 전체 다운로드를 확인합니다.

저장 형식2·기존 설치 서명을 유지합니다. PvE/보상 계산이 달라져 Wi-Fi 프로토콜을 11로 올렸으므로 파티원 전원이 2.17.0으로 업데이트해야 합니다. 기존 랭킹, 4가지 모드, 닉네임·계급, 매주 보상/2주 초기화, 미리보기 걷기 제거와 모션/키 차이는 유지합니다. 서버·DB·실결제와 집사 사절 원본은 변경하지 않습니다. 실제 Android 장시간 FPS·발열·여러 기기 검수는 별도입니다.

## 후반 지역 추가 비교

최종 소스에서 적정 레벨 마법 +6 장비와 실제 레벨/SP 규칙으로 배운 1~5랭크 스킬을 사용했습니다. 같은 조작 정책의 일반 난이도 6직업×48던전은 288/288회 완료했습니다. 6직업×4정예 원정은 같은 장비에서 22/24회 완료했고, 유니크 +10으로 바꾸면 24/24회 완료했습니다. 일반 던전 진행 가능성과 후반 장비 투자의 차이를 확인하는 추가 비교이며, 자동 조작의 미완주는 프로그램 오류와 구분합니다. [추가 수치](PROGRESSION-ALL-ROUTES.json).
