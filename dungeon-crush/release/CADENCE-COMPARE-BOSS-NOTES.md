# 2.20.2 · 걸음 박자, 장비 비교, 메뉴 정렬, 보스 마법

2.20.1의 픽셀 차이별 가변 포즈 시간과 ‘가장 가까운 포즈’ 선택은 접지 포즈의 유지 시간을 다르게 만들고 주기 끝에서 첫 포즈로 일찍 돌아가게 했습니다. 좌우 속도 일치 검사만으로 걸음 리듬이 자연스럽다고 판단한 것이 부족했습니다. 가변 타이밍은 제거하고 8개 전신 포즈를 같은 시간씩, 같은 순서로 표시합니다. 두 접지 포즈는 정확히 주기의 0/50%입니다. 보폭을 캐릭터 키×200에서 키×260으로 늘려 다리 회전만 낮췄습니다. 터치 입력·물리 이동 속도·좌우 대칭·반전 가속은2.20.1과 같습니다. 원화·접지 기준·몸 배율·공격·점프도 보존합니다. 기존의 픽셀 차이 기반 타이밍 생성 도구는 제거했으며 다시 적용하지 않습니다. 발소리는 같은 보행 위상의 두 접지에 맞춰 재생됩니다.

가방 상세·비교는 설명/선택 분리 틀을 제거하고 넓은 비교 창으로 바꿨습니다. 왼쪽은 착용 장비, 오른쪽은 선택 장비이며 이름·아이콘·등급·레벨·강화를 함께 표시합니다. 공격력/HP/집중의 각 장비 옵션 차이와 전체 장비·세트 효과를 반영한 교체 후 수치/전투력 증감을 따로 보여줍니다. 상승은 초록색과 ↑/+/상승, 하락은 붉은색과 ↓/-/하락, 같으면 변화 없음으로 표시합니다. 예를 들어 선택 장비의 HP 자체가+12여도4세트가 깨지면 전체 장비 HP가-145라는 점을 확인할 수 있습니다.6세트 집중 손실도 포함합니다. 빈 슬롯/같은 장비/레벨 제한/읽기 전용 비교를 검사하며, 장착 불가 장비에는 잘못된 전체 능력 감소 예측을 표시하지 않습니다. 노치 여백·확대 글자에서도 두 장비는 나란히 유지하고 창은 안전영역 안에 배치합니다.

오른쪽8개 바로가기는 모든 칸의 폭·높이를 같게 하고 작은 화면에서 너비를 늘려 글자 줄바꿈을 줄였습니다. 글자를 키우면 한 칸만 커지는 대신 전체 행이 같은 높이로 커집니다. 전체 메뉴 카드도 행에 맞춰 늘어납니다. 기본 접기/펼치기·접기, 왼쪽 위 정보만 표시, 타이틀 상점 제거 지시는 유지합니다.

보스 마법은 시전의 큰 마법진·집광, 폭발의 광원·상승 기둥·회전 문양·입자, 커진 투사체를 추가했습니다. 보스 폭발만0.9초, 시전 발사광은0.35초로 늘려 여운을 보강했습니다. 일반 몬스터 효과는 유지하고 보스의 효과에만 적용합니다.16속성의 색/형태를 유지하며 효과 줄이기에서는 단순화합니다. 실제 피해·공격 범위·패턴·타이밍·투사체 충돌 크기·랜덤·보상은 바꾸지 않습니다. 적 효과에 보스 표시와 발생원 정보만 더하며 게임 상태 비교에서 이펙트 외 상태는 같습니다. 경고선은 마지막에 그리며 도넛 중앙 안전지대를 가리지 않습니다. 프레임 장식96/축소24·텍스처48개의 기존 제한을 유지합니다.
