# 2.13.0 지역 확장

- 스토리 12챕터/36던전에서 16챕터/48던전으로 확장합니다. 기존 0~35번 던전과 최대 100레벨, 저장 형식 2는 유지합니다.
- 황혼의 수로, 비취 독늪, 붉은달 공방, 여명의 천상궁에 각 3개 던전과 보스 3종을 추가합니다. 신규 일반 몬스터는 지역별 2종이며, 신규 원화는 총 20종/320포즈입니다.
- 기존 36개 의뢰를 완료한 캐릭터는 다음 의뢰인 잠긴 수문부터 이어갑니다. 새 의뢰도 순서대로 정복하고 보고해야 다음 던전이 열립니다.
- 100레벨 정예 레이드 4개는 해당 지역 의뢰 3개 완료 후 개방합니다. 지역 보스 3종이 5개 전장에 출현하며, 100레벨 장비와 반복 정복 핵 3개를 지급합니다. 주간 첫 레이드 핵 6개 추가 보상은 기존 레이드와 공유합니다.
- 실제 전투 배경을 기존 5장에서 24장으로 늘립니다. 초기 공유 배경 지역 7곳과 신규 던전 12곳에 원화 19장을 추가합니다. 수로 이후에는 같은 챕터 안에서도 던전마다 배경이 다릅니다.
- 현재/다음 레이드 전장의 배경만 준비하고 디코딩 캐시는 최대 3장으로 제한합니다. 필요한 그래픽이 준비되지 않으면 전투를 멈추고 로딩 화면을 표시합니다. 실패하면 재시도하거나 마을로 돌아갈 수 있습니다.
- 16개 지역의 적 공격에 참격, 용광로, 가시, 수정, 물결, 낙뢰, 시계, 월식, 빙하, 용암, 유성, 공허, 수압, 포자, 톱니, 태양 효과를 적용합니다. 플레이어 스킬 원화는 유지합니다.
- 새 보스는 직선·수직 광선·여러 갈래 광선·안전한 중앙이 있는 십자·대각 십자·독/태엽/태양 고리·시차 장판·독침 부채탄을 사용합니다. 위험 경계와 피해 판정은 같은 원/고리/캡슐 선분으로 계산합니다. 이펙트 줄이기에서도 위험 경계는 유지합니다.
- Wi-Fi 프로토콜은 9입니다. 파티원 모두 이번 APK로 업데이트해야 합니다. 기존 버전 참가 시 업데이트 안내를 표시합니다.
- 기존 기합 음량 25%, 보스 음악, 착용/잠금 장비 판매 방지, 체크 판매와 판매 되돌리기, 백업/복원을 유지합니다. 랭킹 서버 연결은 꺼진 상태이며 주소/공개키는 비어 있습니다.

새 원화는 OpenAI image_gen으로 제작하고, 런타임 WebP는 원본 PNG와 디코딩 RGBA가 동일한 무손실 형식으로 변환합니다. 최종 SHA와 원본 출력 식별자는 generated-art-sources.json, 프레임 경계 검수는 frontier-art-review.json에 기록합니다.

코드/브라우저 검사 후 APK/AAB와 Android lint를 실행하는 순서로 빌드합니다. 실제 Android 단말의 조작감, 발열, FPS와 스토어 운영 서명/등록은 별도 검수 대상입니다.
