# 2.14.1 유료 외형 몸 크기 수정

스킨을 장착할 때 캐릭터가 커지거나 작아지는 문제를 수정합니다. 종전에는 투구·후광·무기까지 포함한 전체 그림 높이로 몸 크기를 추정했고, 공격 시트의 모든 동작에 같은 기준값을 적용했습니다. 이 때문에 장식의 형태와 공격 그림의 배치에 따라 몸 크기가 달라졌습니다.

6직업 기본 외형과 스킨 30벌의 대기·기본 공격 3단·스킬 시전 복귀 자세에서 눈높이와 부츠 접지점을 직접 대조했습니다. 확대 얼굴 비교와 기준선, 기본 외형을 함께 표시한 실제 게임 렌더 비교 화면으로 확인합니다. `art-source/premium-body-calibration.json`에 원화 SHA256, 소스 셀과 기준점을 기록했습니다.

보정은 몸 전체에 같은 가로·세로 배율을 적용합니다. 각 동작 안에서는 배율을 고정하고, 달리기·점프·대시는 대기 몸 기준을 공유합니다. 원화 픽셀, 의상·무기의 형태, 스킬 효과, 공격 판정·수치·속도는 변경하지 않습니다. 장식이 머리 위나 몸 바깥으로 돌출되는 디자인 차이는 유지합니다.

`tools/premium_body_calibration.py`가 이 기준을 적용하고, 원화 포장 도구도 같은 보정을 적용하여 재포장 때 기준이 사라지지 않도록 합니다. 검수한 원화의 SHA256이 바뀌면 재검수를 요구합니다.

`tests/premium-size-presentation.test.cjs`는 실제 저장의 스킨 구매·장착·해제를 거쳐 기본 외형과 비교합니다. 30벌 × 대기/3단 공격/시전 5동작 × 양방향 = 300건의 실제 Canvas 눈높이·접지 좌표를 검사하고 직업별 비교 화면을 남깁니다. 기존 원화·전 모션·9스킬·4인 통신·로딩 복구·상점·저장·휴대폰 UI 검사도 유지합니다. 총 52개 검사(코드 24 + Java 2 + Chrome 26) 후 APK/AAB와 Android lint, 기존 설치 서명과 포함 리소스를 검증합니다.

버전은 2.14.1 / versionCode 41입니다. 저장 형식 2와 Wi-Fi 프로토콜 10을 유지하며 기존 앱을 삭제하지 않고 업데이트합니다. 스킨·펫은 여전히 실제 결제 없는 무료 테스트 구매입니다. 집사 사절 원본, 서버와 DB는 수정하지 않습니다.

최종 빌드와 공개 ZIP 검증 결과는 완료 후 기록합니다. 실제 휴대폰 장시간 FPS·발열 검사는 별도입니다.
