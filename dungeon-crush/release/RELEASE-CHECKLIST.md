# 2.10.2 출시 후보 점검

## 이번 버전

- 저장 실패·작업 실패 시 골드/아이템/장착 상태를 작업 전으로 복구합니다.
- 브라우저·Android 저장소의 최신 정상 기록을 선택하고, 이전 정상 기록으로 복구합니다. 정상 기록이 하나도 없으면 기존 내용을 새 기록으로 덮어쓰지 않습니다.
- 설정에서 JSON 백업 파일 저장/복원, 파일 손상·용량·형식 검사, 6직업 요약과 교체 확인을 제공합니다. Android는 시스템 파일 선택기를 사용합니다.
- 장착·잠금 장비 판매 금지와 체크 일괄 판매를 유지합니다. 최근 판매 1회의 장비는 판매 대금을 반환해 복구할 수 있습니다. 이전 버전에서 이미 사라진 장비를 소급 복구하지는 않습니다.
- 전투 그래픽 준비 실패 시 재시도/마을 복귀를 제공합니다. 전투 시작 전 취소한 심연 입장료는 반환하며 중복 반환하지 않습니다. 다른 참가자의 전투가 진행된 경우에는 반환하지 않습니다.
- 100레벨·9개 스킬·6칸 선택 장착에 맞춰 도움말을 갱신했습니다.
- Android 16/API 36, AGP 8.10.1, Gradle 8.11.1로 갱신했습니다. Android 13 이상 뒤로가기 콜백과 시스템 표시 영역/노치 여백을 처리합니다.

## APK 배포와 스토어 제출의 구분

CI의 `DungeonCrush-APK`는 기존 설치를 업데이트할 수 있도록 같은 테스트 서명을 사용합니다. package `com.dungeoncrush.game`, versionCode 35, versionName 2.10.2. APK는 앱을 제거하지 말고 업데이트 설치합니다. 먼저 기존 기록을 백업하세요.

CI의 `DungeonCrush-Unsigned-Store-AAB`는 release 모드의 **서명되지 않은** 스토어 준비 번들입니다. 이 파일은 그대로 스토어에 제출할 수 없습니다. 운영자가 관리하는 업로드 키로 서명하고 Play App Signing을 설정해야 합니다. 테스트 키는 공개된 기본 비밀번호를 사용하므로 실제 운영 서명 키로 사용하지 않습니다. 스토어 앱 서명이 테스트 APK와 달라지면 기존 테스트 앱 위에 설치되지 않습니다. 설정에서 백업한 파일로 성장 기록을 옮길 수 있습니다.

실제 출시 키나 계정 자격 증명을 저장소 또는 채팅에 넣지 마세요. 서명·스토어 등록은 소유자가 관리하는 비밀 저장소와 Play Console에서 마무리합니다.

## 자동 검증

빌드 워크플로는 기존 전투·6직업 모션·전체 그림·글꼴·장비·4인 네트워크·휴대폰 UI 검사와 새 저장/백업/판매 되돌리기/로딩 복구 검사를 실행합니다. APK의 패키지, versionCode, 기존 서명과 포함 스크립트 바이트를 검증합니다. AAB는 release 모드로 별도 빌드합니다.

## 실제 Android 기기로 남은 확인

자동 Chrome 검사는 Android 시스템 파일 선택기나 실제 단말의 성능을 대체하지 않습니다. 공개 출시 전에 아래를 수행해야 합니다.

- 이전 versionCode 34 설치에 35를 덮어 설치하여 6직업 레벨/장비/스킬 유지 확인
- 시스템 파일 선택기로 로컬/선택한 드라이브에 백업, 취소, 잘못된 파일, 정상 복원 확인
- 앱 전환·전화·화면 잠금 후 싱글 일시정지와 입력 초기화, LAN 종료 안내 확인
- 최소 지원 Android 6(API 23, 업데이트된 System WebView) 및 Android 13/16에서 실행, 뒤로가기와 종료 확인, 노치·제스처 영역, 작은 휴대폰·태블릿·분할 화면 확인
- 보급형/중급형 단말에서 30분 플레이, 4인 스킬 동시 사용 시 프레임률·메모리·발열 확인
- 서로 다른 실제 기기 2~4대로 협동/개인전, 참가·이탈·방장 종료·공유기 격리 환경 확인
- Play Console 내부 테스트, 사전 출시 보고서, 대상 연령/콘텐츠 등급·데이터 보안 설문 확인
