# 2.20.3 · 양발 보행과 전체 메뉴 정렬

사용자 재현 화면은 마을의 8칸 바로가기가 아니라 **모험가 메뉴 전체 화면**입니다. 외형 카드의 설명 줄바꿈으로 첫 행의 높이가 커지고 아래 행이 잘렸습니다. 전체 화면을 12개 목적지의 4열×3행으로 정리하고, 중복된 마을 복귀 카드는 제거했습니다. 제목의 시작선과 카드 폭·높이를 통일합니다. 내용의 실제 최소 높이를 측정해 확대 글자에서는 같은 높이를 유지하며 스크롤합니다. 닫기·뒤로·포커스 복귀·입력 차단은 유지합니다.

기존 이동은 한 장의 전신 이미지를 그리는 방식이었지만, 원화의 두 반주기에서 같은 쪽 발이 반복돼 양발 교대가 잘 읽히지 않았습니다. 기본 6종과 외형 30종의 이동 전신 시트를 새로 제작했습니다. 각 시트는 8포즈이며 가까운 다리와 먼 다리의 명암을 구분합니다. 몸을 잘라서 움직이거나 전신을 겹쳐 그리지 않습니다.

- 달리기는 8포즈를 동일한 시간 간격으로 표시합니다. 발 접촉 두 지점 사이의 바닥 기준을 사용해, 공중 포즈의 발바닥을 강제로 바닥에 붙이면서 몸까지 내려가던 현상을 방지합니다.
- 낮은 입력의 이동은 지면을 딛는 자세를 사용합니다. 오른발·왼발 두 반주기에 같은 간격을 적용하고 발바닥을 접지합니다.
- 일반 이동의 먼지·속도 선·외형 문양을 제거해 발 디딤을 가리지 않습니다. 대시 효과는 유지합니다.
- 직업별 키 차이를 유지하도록 눈높이와 불투명 발바닥을 측정해 각 이동 시트의 기준 배율을 맞춥니다. 수동 눈높이는 시각 보정값이며 1픽셀 단위의 해부학 정확도를 의미하지 않습니다.

실제 이동 속도, 좌우 입력, 가속·반전, 공격·점프·대시, 적 데이터, 보상·저장·Wi-Fi 프로토콜은 바꾸지 않습니다. 새 원본 PNG·포즈 가이드·압축본 해시와 측정값은 `art-source/locomotion2203/`, `generated-art-sources.json`, `locomotion-review.json`에 기록합니다. 원본 PNG는 APK에 포함하지 않습니다.

검증은 원본 알파에서 독립적으로 측정한 발바닥과 실제 렌더링의 접지 위치를 비교합니다. 36종×8시점×두 방향×느린 이동/달리기 1,152조합을 검사하며, 기존 128개 캐릭터·몬스터의 30,720개 이동/공격 렌더와 좌우 픽셀 비교도 유지합니다. 메뉴는 사용자 화면 비율과 작은 화면·안전영역·1.4배 글자로 모든 카드의 크기와 가시성을 검사합니다. 연속 이동 영상과 포즈 시트는 자동 수치 검사와 별도로 확인합니다.

이 문서는 구현 범위입니다. 완료된 빌드·게시 결과는 최종 배포 검증 기록과 HANDOFF에 기재합니다. Android 업데이트 설치, 실제 손가락 조작감, 물리 Wi-Fi 2~4대, 장시간 발열·음량은 실기기 검수로 남습니다.
