# 2.20.4 · 장비 그림·강화 화면·가방 비교

신고한 린 하의 왼쪽 조각은 원본 아틀라스의 셔츠가 같은 크기의 격자 경계를 넘어왔는데도 6열×5행 배경 위치로 표시한 결과입니다. 기존 원본 이미지3개의 바이트는 보존했습니다. 추가 지시에 따라 아리아·엘리안 장비12개는 나머지4직업과 같은 투명 배경·무테 원화로 새로 제작했습니다. 두 직업의 스킬 원본은 유지합니다. 생성 PNG·참조·알파 검수·정확히 같은 RGBA의 무손실 WebP는 `art-source/equipment2204/`와 이미지 매니페스트에 기록합니다. 기본4직업24개/새 무테2직업12개/재화6개의 영역을 확인하고, 장비마다 독립된 SVG 뷰포트로 잘라 비율을 유지합니다. 바깥 여백에 이웃 이미지가 다시 보이지 않도록 안쪽 뷰포트를 별도로 클리핑합니다. 무기 공격 아이콘·물약·제작·판매·착용·상세·강화도 같은 렌더러를 사용합니다. [영역·원본 해시](../equipment-icon-review.json).

## 공식 게임 참고

- [던전앤파이터 공식 강화 가이드](https://df.nexon.com/guide?no=1230): 선택한 장비, 현재/다음 능력치, 보유/필요 재료, 실행 버튼의 순서를 확인했습니다. 가이드에 연결된 안전 강화 화면을 실제 열어 비교했습니다.
- [디아블로 이모탈 공식 초보자 가이드](https://news.blizzard.com/ko-kr/article/24165043/디아블로+이모탈+초보자+가이드): 장비 정비와 대장장이의 재료·강화 흐름을 참고했습니다.

두 게임의 정보 배치를 참고하되 화면 이미지나 그림은 복사하지 않습니다. 던전크러시의 기존 골드/철편 비용, 강화 효과, 최대+15, 확정 성공·파괴/하락 없음은 유지합니다.

## 실제 동작

강화 화면은 왼쪽에 보유 장비, 오른쪽에 선택 장비·현재→다음 단계·능력치·증가량·골드/철편 보유량과 필요량을 표시합니다. 장비 선택만으로 비용이 들거나 확인창이 뜨지 않습니다. 하단의 확정 강화를 누르면 같은 정보로 최종 확인하고 처리합니다. 취소/닫기/뒤로는 비용을 쓰지 않습니다. 재료 부족·최대 단계는 비활성으로 표시합니다. 확인 사이 장비 단계가 바뀌면 거절하고 자원을 다시 검사합니다. 중복 클릭으로 두 번 차감하지 않습니다. 작은 화면에서는 내용만 스크롤하며 하단 실행 버튼을 유지합니다.

가방의 미착용 장비는 같은 부위의 착용 장비와 비교합니다. 공격/생명/집중 중 하나라도 오르면 녹색↑이며, 교체 결과 세트 능력만 오르는 경우도 포함합니다. 다른 옵션이 내려가더라도 하나가 오르면 녹색입니다. 상승 옵션이 없으면 빨간색↓이며 같은 수치는 '상승 옵션 없음'입니다. 화살표는 모든 능력이 좋아진다는 뜻이 아닙니다. 세트 손실을 포함한 정확한 변화는 기존 왼쪽 착용/오른쪽 선택 상세 비교에서 확인합니다. 레벨 제한 장비도 개별 옵션을 비교하지만 착용 제한은 유지합니다. 착용 중인 장비에는 화살표를 표시하지 않으며 교체·해제·강화·필터·정렬 시 갱신합니다.

기존 이동·보스 마법·메뉴 접기·닉네임 변경권·성장·주간 보상/2주 초기화·랭킹·자동 저장·Wi-Fi는 유지합니다. 서버·결제·DB를 연결하지 않습니다.

## 검수 범위

원본 해시 보존,42개 아이콘의 정사각형/가로형 실제 렌더와 독립 Canvas 영역 추출 비교,6직업×6부위×16강화 단계576개 비용·수치 예측,가방 화살표/필터/착용 갱신,1280×591/740×360/640×296 안전영역·1.4배 글자·스크롤·확인/취소·중복 클릭·상태 변경·재료 부족·최대/빈 가방을 검사합니다. 기존 전체71개 회귀와 APK/AAB/lint/서명/포함 파일/공개 다운로드 결과는 배포 검증에 기록합니다.

실기기 업데이트 설치, 손가락 터치·시스템 글자/키보드, 물리 Wi-Fi2~4대, 장시간 FPS·발열·음량은 실기기 검수로 남습니다. 자동 검사 성공을 모든 환경의 오류0 보장으로 표현하지 않습니다.
