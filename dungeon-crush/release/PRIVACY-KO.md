# 던전크러시! 개인정보 처리 안내

적용 버전: 2.10.2

던전크러시!는 별도 계정 가입 없이 플레이하는 액션 RPG입니다. 앱에는 광고, 분석, 결제 또는 원격 오류 수집 SDK를 포함하지 않습니다.

## 기기에 보관하는 정보

캐릭터의 성장, 장비, 골드, 퀘스트 진행과 설정을 앱 전용 저장 공간과 WebView 저장 공간에 보관합니다. 저장 오류 복구를 위해 이전 정상 기록도 기기에 보관합니다. 이 정보는 개발자 서버로 전송하지 않습니다.

앱 데이터 삭제 또는 앱 제거 시 기기 안의 기록도 삭제됩니다. Android 자동 클라우드 백업은 사용하지 않습니다. 삭제하거나 기기를 바꾸기 전에 설정의 ‘백업 파일 저장’을 이용하세요.

## 같은 Wi-Fi에서의 멀티플레이

사용자가 방을 열거나 참가하면 로컬 네트워크의 상대 기기와 접속 주소, 사용자가 입력한 닉네임, 캐릭터와 게임 진행 상태를 교환합니다. 별도 인터넷 중계 서버는 사용하지 않습니다. 상대 기기가 닉네임과 게임 상태를 볼 수 있습니다. 앱을 떠나거나 방에서 나가면 연결을 종료합니다.

## 직접 만드는 백업 파일

설정에서 요청한 경우에만 Android 파일 선택기를 통해 선택한 위치에 성장 기록을 저장하거나 사용자가 고른 파일을 읽습니다. 전체 저장 공간 접근 권한을 요청하지 않습니다. 파일을 클라우드 드라이브나 다른 사람에게 전달하는 것은 사용자의 선택이며, 선택한 서비스의 정책이 적용됩니다. 백업 파일은 암호화하지 않으므로 직접 관리하고, 필요하지 않으면 파일 관리자에서 삭제하세요.

복원은 파일 내용을 검사하고 캐릭터별 요약을 표시한 뒤 사용자가 확정할 때만 진행합니다. 현재 기록을 교체하므로 먼저 별도로 백업하세요.
