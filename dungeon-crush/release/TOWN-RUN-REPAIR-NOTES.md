# 2.20.1 · 마을 화면 정리와 양방향 달리기 재검수

사용자 지시 범위만 수정합니다. 메인 타이틀에 외형·펫 상점을 다시 넣지 않습니다. 외형·펫은 마을에서 이용합니다. 마을 왼쪽 위에는 계급·닉네임·골드·직업·레벨·EXP만 표시하고 모서리의 안전영역+6px에 배치합니다. 캐릭터 선택·도움말·Wi-Fi·설정 중복 버튼은 숨기며 오른쪽 전체 메뉴에서 이용합니다. 오른쪽 아래는 처음에 ‘메뉴 펼치기’만 표시하고 펼친 뒤 ‘메뉴 접기’로 되돌립니다. 기존 8개 바로가기와 12개 전체 메뉴 기능은 유지합니다. Wi-Fi 파티는 던전 해금/입장 조건과 별개로 대기실을 바로 열어 파티를 먼저 구성할 수 있습니다.

기존 좌우 검사에는 같은 수치의 이동 입력만 사용한 빈틈이 있었습니다. 터치 조이스틱은 링의 끝까지 밀어야 최고 속도가 나왔고 수평 이동 중 미세한 세로 흔들림도 속도에 영향을 줬습니다. 중앙 12%는 정지, 반경 60%부터 최고 속도, 수평/수직 축에서 약14도 이내의 작은 흔들림은 해당 축으로 보정합니다. 그 사이의 아날로그 정밀 이동은 유지합니다. 방향을 바꿀 때는 이전 방향의 속도를 이어받지 않고 같은 가속으로 새 방향을 시작하며 보행 위상을 되감거나 초기화하지 않습니다. 기본 속도·대시 거리·점프·공격 시간·성장 수치는 보존합니다.

달리기의 8개 전신 포즈는 하체의 프레임 간 차이가 서로 다른데도 같은 시간씩 표시했습니다. 6종 기본과 30벌 각각의 실제 하체 픽셀 차이를 측정해 순환 재생 시점을 보정했습니다. 두 접지 포즈는 한 주기의 0/50%를 유지하고 가까운 포즈 사이에는 짧은 시간, 변화가 큰 포즈 사이에는 긴 시간을 배분합니다. 원화·접지 기준점·몸 배율·포즈 순서는 그대로이며 매 순간 불투명한 전신 한 장만 그립니다. 전신 crossfade나 다리 분할은 추가하지 않습니다. 재현 도구는 `tools/calibrate-run-timing.py`, 측정·원본 해시는 `art-source/run-timing-review.json`입니다.

검수는 모든 6직업에 대해 30/60/120Hz, 세 가지 조이스틱 거리와 작은 세로 흔들림, 좌우 출발·반전을 포함합니다. Chrome에서는 세 화면 크기에서 실제 CDP 터치로 서로 다른 좌우 밀기 거리를 주고 입력·거리·최종 속도를 기록합니다. 36종×8포즈의 실제 좌우 렌더 픽셀도 거울 비교하고 각각 비교 시트를 남깁니다. 기존 128개 캐릭터/몬스터 30,720개 이동·공격 렌더 검사와 4인 전투, 메뉴/확대 글자/변경권/랭킹/저장 회귀 검사도 계속 실행합니다. 자동 검사를 실기기의 조작감/FPS/발열 검사 완료로 표현하지 않습니다.

기존 닉네임 최초 무료 저장/변경권 1개 사용, 3,900원 상품 및 결제 연결 전 구매 불가, 4가지 모드·공유 유저 AI PK·랭킹·매주 보상/2주 초기화·걷기 없는 미리보기·자동 저장은 유지합니다. 서버·DB·실결제는 연결하지 않습니다. 설치 버전50, 저장 형식2, Wi-Fi12이며 기존 서명을 유지합니다.
