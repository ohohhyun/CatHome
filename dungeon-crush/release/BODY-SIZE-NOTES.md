# 2.20.5 · 기본·유료 외형 신체 크기 통일

캐릭터 선택과 마을의 제보 화면을 재현했습니다. 직업 배율이 `[1,1.08,1.16,.92,.84,1.04]`여서 최대/최소가 약38% 차이 났고, 선택창은 기본 원화에만 신체 기준점을 적용하고 유료 원화는 이미지 전체 크기로 표시했습니다. 마을 주민도 플레이어와 별개로340 높이에 그려져 과하게 컸습니다. 이전의 큰 키 차이를 보장하던 검사는 최신 사용자 지시에 맞춰 같은 신체 스케일을 보장하도록 바꿉니다.

6직업의 배율은 모두1입니다. 원본 그림마다 다른 인체/여백/카메라 차이는 기존 신체 기준점과 보정 참조값으로 맞춥니다. 가로·세로를 같은 비율로 조절해 근육·체형·의상 비율을 보존합니다. 유료30종은 해당 기본 직업과 같은 신체 스케일입니다. 모자·무기·망토·장식의 크기로 몸을 다시 줄이지 않습니다. 보행 보폭의 배율도 같은 기준을 사용하며 실제 이동 속도와 입력, 충돌, 피해, 사거리, 점프 궤적, 성장·장비·저장은 유지합니다.

선택창은 원화36개 모두에서 눈높이와 가장 낮은 신발 바닥을 확인해 같은 신체 높이·바닥에 맞춥니다. 원본 고해상도 그림을 유지합니다. 기준점은 `art-source/selection-presentation.json`에 원본 해시와 함께 기록했습니다. 수동 기준점의 오차는 원본에서 약±12픽셀로, 수치 검사 통과가 해부학적1픽셀 정확도를 의미하지 않습니다. 무기나 모자가 더 높게 솟는 차이는 신체 크기와 구분합니다.

마을 사람형 NPC3종도 같은 신체 기준과 바닥으로 배치하고 이름표·터치 영역·그림자를 맞춥니다. 원본 NPC 그림은 보존합니다. 몬스터·보스 크기와 전투 판정은 바꾸지 않습니다.

검수는 선택창36종×4화면/안전영역144개, 실제 합성 렌더36종의 공통 신체 스케일·바닥·단일 전신, 실제 마을 NPC3종, 실제 착용한 유료30종의 마을·전투·고정 미리보기 카메라 및 이동·공격·점프·대시·스킬 전환을 포함합니다. 기존 전 동작/좌우·4인·성장·닉네임 변경권·랭킹·주간 보상/2주 초기화·저장·장비 비교·가방 화살표·강화 검사도 유지합니다.

현재는 구현·검수 범위 기록입니다. 최종 전체71개 검사·APK/AAB·Android lint·서명·포함 파일·공개 다운로드 결과는 배포 기록에 기재합니다. Android53→54 실제 업데이트 설치·보존, 물리 Wi-Fi2~4대, 시스템 글자·키보드·손가락 조작·장시간 FPS/발열/음량은 실기기 검수로 남습니다.
