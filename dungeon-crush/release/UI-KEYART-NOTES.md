# 2.15.0 캐릭터 원화 · 외형 미리보기 검수

기본 캐릭터 6명과 외형 30벌의 원화 36장을 제작·검수하고 무손실로 포장했습니다. 전체 자동 검사와 Android 빌드·서명/리소스 검증을 통과한 소스로만 APK를 배포합니다.

## 수정 내용

- 캐릭터 선택에서 기본 6명 또는 장착한 외형의 전신 일러스트를 표시합니다. 몸·발·무기를 화면 안에 담고 가로·세로 비율을 유지합니다.
- 외형 상품을 누르면 해당 의상의 원화, 실제 동작, 실제 스킬 효과를 탭으로 확인합니다. 구매·장착·해제는 같은 상세 화면에서 사용합니다.
- 휴대폰에서 상점의 가용 너비를 사용하고, 동작 선택은 드롭다운으로 정리했습니다. 상품 목록과 구매 영역을 분리하고 노치 여백·확대 글자를 검사합니다.
- 미리보기에서 동작에 따라 자동으로 바뀌던 카메라 배율을 고정했습니다. 같은 외형도 대기/달리기보다 공격/점프/스킬이 작게 보이던 원인입니다. 큰 스킬은 사용자가 직접 넓게 보기로 바꾸고 기본 배율로 돌아올 수 있습니다.
- 원화 화면에서는 보이지 않는 전투 미리보기를 계속 계산하거나 그리지 않습니다. 원화와 동작 로딩 실패 각각에 재시도를 제공합니다.

## 실제 화면 검사

- 실제 상점 버튼으로 30벌을 장착하고, 마을과 전투에서 표시된 결과를 기본 6명과 비교했습니다. 해제 후 기본 몸으로 돌아오는 것까지 확인했습니다.
- 원화의 테두리나 장식 전체 높이 대신 기존에 따로 검수한 눈높이와 발 접지점을 사용했습니다. 실제 Canvas 변환 좌표에서 월드 높이 260과 눈/발 오차를 측정합니다. 눈높이 허용 오차는 월드 1.5 단위이며 휴대폰 표시에서 1픽셀 미만입니다.
- 740×360에서 기존 미리보기의 기준 몸 높이는 대기/달리기 112.57px, 공격/점프 76.15px, 스킬 59.60px였습니다. 수정 후 기본 카메라는 모든 동작·외형에서 75.80px로 유지됩니다. 이는 카메라 기준 길이이며 점프의 실제 위치나 공격 자세의 변화까지 고정한다는 뜻은 아닙니다.
- 30벌의 대기·달리기·공격·점프·회피·스킬 영상을 기록했습니다. 실제 선택된 동작 버튼으로 구간을 식별한 뒤 추출한 12개 비교표에서 하체/무기 잘림과 갑작스러운 비율 변화를 육안으로 확인했습니다.
- 모든 외형을 실제 장착한 뒤 캐릭터 선택창으로 돌아가 해당 의상의 원화가 표시되는지, 재입장 시 외형이 유지되는지 검사합니다.
- 40상품 구매/취소/장착/해제/재실행, 외형 30벌의 9스킬 발동, 펫 10종, 좁은 화면·노치 여백·1.4배 글자, 원화/스프라이트 로딩 실패와 복구를 검사했습니다.
- 초기 전체 CI에서는 타이틀 버전 검사가 이전 버전 2.14.1을 고정해 실패했습니다. 검사를 `app/build.gradle`의 versionName과 대조하도록 고쳤으며, 최신 소스 `f616e095a66be0d3d31c8e030d9022b3cad536e3`의 전체 검사는 [빌드 43366493827](https://github.com/ohohhyun/CatHome/actions/runs/43366493827)에서 모두 통과했습니다. 실패한 실행에서는 APK를 만들지 않았습니다.
- 모든 40상품을 반복하는 15분 이상 브라우저 검사도 두 번 수행했습니다. 정적 원화에서 불필요한 동작 로딩을 줄인 후 DOM과 회수 후 메모리의 지속 증가가 없는지 확인했습니다. 실제 Android 단말의 장시간 FPS·발열 측정은 포함하지 않습니다.

검사 수치는 [UI-KEYART-QA.json](UI-KEYART-QA.json), 실제 장착 비교는 [Appearance-2.15.0-World-Comparison.png](Appearance-2.15.0-World-Comparison.png)에 있습니다.
