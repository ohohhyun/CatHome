# UI 참고와 적용

사용자 요청에 따라 액션 RPG의 정보 계층과 랭킹 구성을 확인했습니다. 다른 게임의 원화·로고·UI 이미지는 앱에 복사하지 않았습니다. 던전크러시의 기존 원화와 자체 CSS/HTML을 사용합니다.

- [디아블로 이모탈 공식 업데이트](https://news.blizzard.com/en-us/article/24316732/a-mysterious-stranger-arrives-in-westmarch): 직업/콘텐츠별 랭킹 개념을 참고했습니다.
- [블리자드 공식 포럼의 랭킹 화면](https://us.forums.blizzard.com/en/diablo-immortal/t/tempest-challenge-rift-leaderboard-and-mats-in-mailbox/8717): 범주 선택, 순위 목록과 플레이 캐릭터 기록을 분리하는 구성을 확인했습니다.
- [패스 오브 엑자일 공식 래더](https://poe.kakaogames.com/ladders): 순위/캐릭터/직업/레벨을 분명히 나누는 표 구성을 참고했습니다.

적용: 검푸른 배경과 브론즈/금색 강조, 명확한 주 행동 버튼과 보조 버튼, 통일된 메뉴 프레임/선택 테두리/키보드 포커스, 랭킹 범위·종목·직업 필터·고정 기록 요약. 작은 가로 화면에서는 설명 영역과 표를 별도로 스크롤하며 메뉴와 버튼은 접근 가능하게 유지합니다.

서버가 없는 현재 ‘전체 랭킹’은 연결 전 상태를 명시합니다. 기기의 6캐릭터 기록을 다른 이용자의 전역 순위로 표현하지 않습니다.
