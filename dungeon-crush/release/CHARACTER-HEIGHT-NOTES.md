# 2.16.0 선택 배경과 캐릭터 키

선택창에 새벽 성채 회랑 배경을 추가하고 캐릭터마다 다른 실제 몸 키를 적용합니다. 기본 선택 전신 5장은 투명 배경으로 별도 제작했습니다. 엘리안의 기존 투명 원화와 상점·카드의 36개 기존 일러스트는 유지합니다. 생성 원본과 해시는 `generated-art-sources.json`에 기록합니다.

| 캐릭터 | 카엘 대비 눈높이~발바닥 |
|---|---:|
| 베인 | 116% |
| 린 | 108% |
| 엘리안 | 104% |
| 카엘 | 100% |
| 세라 | 92% |
| 아리아 | 84% |

모자·무기·머리 장식 대신 실제 눈과 발바닥을 기준으로 선택 원화를 배치합니다. 월드 스프라이트도 기존 직업별 눈/발 기준을 정규화한 뒤 같은 키 비율을 적용합니다. 모든 외형 30벌은 해당 직업의 키를 따르며, 가로세로 비율을 유지합니다. 발 위치와 점프 이동량을 보정하고 그림자·이름표·미리보기 카메라도 맞췄습니다. 능력치·피격/공격 판정·저장 데이터·이동 속도는 유지합니다.

빠른 선택 전환에서 큰 투명 원화의 onload 이후에도 비동기 디코딩이 끝나지 않아 캡처에 빈 화면이 나타나는 문제를 수정했습니다. 이미지 decode 완료 후에만 표시/ready를 설정합니다.

추가 검사는 실제 이미지 투명도와 배경 디코딩, 4개 화면 크기(1280×591, 740×360, 640×296, 1024×768), 6직업 공통 발 위치와 서로 다른 몸 키, 화면 밖 잘림, 배경 파일 실패 시 사용 가능한 대체 화면, 실제 캔버스 6인 몸 높이와 상태 불변을 확인합니다. 기존 30벌 몸 크기·마을/전투·미리보기·전체 모션·몬스터 방향·전투/저장 검사도 계속 실행합니다.

로컬 공격 유지 검사에서 고정 1.9초 안에 25프레임을 요구하면 동시 브라우저 부하에 따라 실패했습니다. 실제 버튼을 유지한 상태로 30개 이상 공격 렌더와 연계 3단 도달을 기다리도록 바꿨습니다(최대 15초). 콤보 되감김·이미지 로딩·누락·전신 잔상에 대한 기존 검사는 그대로입니다.

전체 자동 검사를 통과한 소스로만 APK를 만들고 Android lint·기존 설치 서명·최종 포함 자원까지 검증한 뒤 공개 ZIP을 게시합니다. 게시 후 로그인 없는 전체 다운로드의 크기·SHA-256·ZIP CRC·내부 APK 해시도 확인합니다. 결과와 정확한 소스/빌드 주소는 HANDOFF에 기록합니다. 실제 Android 장시간 FPS·발열·업데이트 저장 보존·복수 기기 Wi-Fi 검수는 별도입니다.
