# 스토어 설명 초안

앱 이름: 던전크러시!

짧은 설명: 6개 직업으로 성장하고, 같은 Wi-Fi의 동료와 던전에 도전하는 액션 RPG

## 상세 설명

잿빛 변경에서 여명의 천상궁까지, 나만의 캐릭터를 키워 던전을 정복하세요.

- 서로 다른 전투 방식의 6개 직업: 검사, 창술사, 격투가, 거너, 마법사, 프리스트
- 16챕터·48개 던전과 최대 100레벨 성장
- 100레벨 정예 레이드 4개와 24개 전투 배경
- 직업별 9개 스킬, 직접 구성하는 6칸 스킬 배치
- 장비 파밍, 비교, 강화, 제작과 세트 효과
- 같은 Wi-Fi에서 최대 4인 협동 플레이
- 30레벨부터 2~4인 개인전
- 인터넷 연결 없이 즐기는 싱글 플레이
- 기기 안 자동 저장과 직접 저장하는 백업 파일

상점에서는 판매할 장비만 체크할 수 있습니다. 장착하거나 잠근 장비는 판매하지 않으며, 최근 판매 1회를 되돌릴 수 있습니다.

가로 화면 플레이를 지원합니다. 멀티플레이는 같은 로컬 네트워크와 동일한 게임 버전이 필요합니다. 앱을 삭제하기 전 설정에서 성장 기록을 파일로 백업하세요.

## 등록자가 확정할 항목

개발자 표시명과 지원 이메일, 개인정보 처리 안내의 최종 공개 URL, 콘텐츠 등급 설문, 데이터 보안 설문, 대상 연령, 실제 기기에서 촬영한 스크린샷과 스토어 아이콘/피처 그래픽. 초안은 게임의 기능 설명이며 스토어 심사 승인을 뜻하지 않습니다.
