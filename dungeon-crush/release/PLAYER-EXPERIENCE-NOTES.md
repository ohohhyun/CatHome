# 2.19.0 · 모험가 이름, 이동 모션, 메뉴와 몬스터 음성

## 변경과 참고

- 시작은 닉네임 생성 → 캐릭터 선택 → 마을입니다. 한글 2~8자, 영문·숫자 4~16자이며 혼합 이름은 한글2/영문·숫자1로 계산해4~16단위입니다. 완성형 한글·영문·숫자만 허용하고 NFC/NFKC를 정규화합니다. 모든 캐릭터가 같은 이름/기존 유저 ID를 사용하며 계급을 앞에 표시합니다.
- [메이플스토리 공식 운영정책](https://maplestory.nexon.com/Common/Footer/OperationPolicy)과 [넥슨 공개 운영정책](https://m.nexon.com/terms/519)의 비속어·선정성·혐오·운영자 사칭·변형 표현 범주를 참고해 독립적인 로컬 규칙을 구현했습니다. 소문자 비교, 숫자 치환·삽입, 반복 문자, 한/영 혼합 우회를 검사합니다. 일반 이름(Assassin/Cassiopeia/Sussex/Scunthorpe/Dickens/새끼고양이 등)의 과잉 차단도 검사합니다. 공유 유저 정보와 Wi-Fi 입장에도 같은 규칙을 적용합니다. 타사 게임 코드·비공개 금칙어 DB는 사용하지 않습니다. 오프라인 목록은 모든 언어/맥락/우회를 완벽히 판단하는 서버 운영 필터가 아닙니다.
- 이전 규칙으로 만든 이름이 새 규칙에 맞지 않으면 다음 캐릭터 선택 전에 새 이름을 정합니다. 유저 ID·점수·레벨·XP·아이템·보상 기록은 보존합니다. 생성/변경 저장 실패 시 기록을 바꾸거나 다음 단계로 넘어가지 않습니다. 첫 생성과 설정 변경 모두 IME 조합 중 제출을 방지합니다.
- 실제 좌우 이동 거리는 기존부터 같았습니다. 어색함은 보폭·셀 전환 주기와 감속/방향 반전 중 시선에 있었습니다. 고정320월드단위 보폭을 키에 비례한200단위로 조정하고, 추가 기울기/상하 흔들림을 줄였습니다. 이동 중에는 실제 속도 방향을 바라보며 공격 조준은 유지합니다. 부동소수점 오차로 접지 경계에서 반대쪽 셀을 선택하지 않도록 보행 위상을 안정화했습니다. 6직업·30외형에 같은 규칙을 적용하고, 전투 수치·물리 이동 속도·대시·점프·공격 시간은 보존합니다. 미리보기는 이전 요청대로 걷기 없이 달리기·공격·점프·스킬 하나를 반복합니다.
- [던전앤파이터 공식 UI 리뉴얼 안내](https://df.nexon.com/community/news/update/2925844?categoryType=0)의 일관된 시각 언어와 익숙한 기능 배치 원칙을 참고했습니다. 메뉴·설정·가방·스킬·모드 선택에 부드러운 모서리, 차분한 남색 패널, 통일한 금색 주요 버튼과 선택/포커스 표시를 적용했습니다. 타사 게임 이미지·아이콘은 포함하지 않습니다.
- 플레이어용 성장 백업 파일 저장/불러오기와 관련 웹·Android API를 제거했습니다. 앱 내부 자동 저장, 이전 정상 기록 자동 복구, 실패 시 원자적 롤백은 유지합니다. 기존에 사용자가 선택한 멀티 PK 상대 정보 코드/파일 공유는 대전 기능이므로 유지하고 전용32KB Android 파일 API로 분리했습니다.
- 몬스터를 야수·거한·망령·석상·기계·곤충·비전·신성 8계열로 분류하고 시전/피격/사망24음을 추가했습니다. [Ogrebane Monster Sound Effects Pack(CC0)](https://opengameart.org/content/monster-sound-effects-pack)의 비언어 괴물 녹음을 편집했습니다. 원본 ZIP/개별 WAV SHA와 파생 Ogg SHA·길이를 `combat-audio-sources.json`에 기록하고 `audio-source/`의 base64로 오프라인 포장합니다. 외부 음원 요청은 없습니다. 음량·음높이·페이드로 과한 겹침을 줄이고 최대2개 몬스터 음성/전체10효과+1캐릭터 음성, 거리 감쇠, 개체별 재생 간격을 적용합니다. 기존 효과음 슬라이더/일시정지/백그라운드 정리와 낮은 캐릭터 기합 음량을 유지합니다. PvP에서는 몬스터 음성이 나오지 않습니다.
