# 집사 사절! · 퇴근길 대작전

집으로 가는 길, 달려드는 고양이에게 집사로 간택되는 것을 피하는 세로형 모바일 아케이드 게임입니다. 10개 골목을 모두 완료하면 **무한 모드**가 해금됩니다.

## APK 받기

이 저장소의 **Actions → Build installable APK → 가장 최근 성공한 실행**을 엽니다. 아래쪽 **Artifacts → CatHome-APK**를 내려받아 압축을 풀면 `app-debug.apk`가 있습니다. GitHub 로그인이 필요합니다.

휴대폰에 APK를 옮겨 설치합니다. 설치한 파일 앱에 '알 수 없는 앱 설치' 허용이 필요할 수 있습니다. 테스트용 APK이며 Play 스토어 배포용 서명은 아닙니다.

## Android Studio에서 열기

1. 이 페이지의 초록색 **Code → Download ZIP**을 눌러 압축을 풉니다.
2. Android Studio의 **Open**으로 `settings.gradle` 파일과 `app` 폴더가 들어 있는 폴더를 엽니다.
3. **Trust Project**를 선택하고 Gradle Sync를 기다립니다. 처음에는 인터넷으로 도구를 받습니다.
4. SDK 설치가 필요하다고 나오면 Android SDK 35 설치를 허용합니다. Gradle JVM은 Android Studio의 내장 JDK 17 이상을 사용합니다.
5. **Build → Generate App Bundles or APKs → Generate APKs** 또는 버전에 따라 **Build APK(s)** 실행.
6. `app/build/outputs/apk/debug/app-debug.apk`가 생성됩니다.

Windows 터미널에서는 프로젝트 폴더에서 `gradlew.bat assembleDebug`를 실행할 수도 있습니다. 기본 Android Studio 설치 경로의 내장 Java를 사용하며, 다른 위치에 설치했다면 `JAVA_HOME`을 맞춰야 합니다.

## 모드 구성 · v0.5

시작 화면에 **일반 모드 / 무한 모드**가 큰 버튼 두 개로 표시됩니다.

- **일반 모드**: 총 20단계. 단계가 오를수록 속도와 고양이 등장 빈도가 증가하고 11~20단계는 더 어렵습니다. 20단계를 완료하면 귀가 엔딩입니다.
- **무한 모드**: 일반 모드 10단계를 완료하면 해금됩니다. 시작 화면의 별도 무한 모드 버튼으로 들어갑니다. 일반 11단계에 들어가도 자동으로 무한 모드로 바뀌지 않습니다.
- 일반 모드 10단계 이후에도 11~20단계를 계속 진행하거나, 시작 화면으로 돌아가 무한 모드를 선택할 수 있습니다.
- 무한 모드는 별도 점수/최고 구간 기록으로 끝없이 진행합니다. 20초마다 다음 구간으로 넘어갑니다. 실패하면 무한 1구간부터 재도전합니다.
- 무한 모드를 해도 일반 모드 완료 단계는 변하지 않습니다.

## 끊김 완화 및 추가 패턴 · v0.5

- 매 프레임 반복하던 점수판/버튼 HTML 교체를 제거하고, 값이 달라질 때만 최대 초당 10회 갱신합니다.
- 도트 캐릭터와 건물을 미리 그림으로 만들어 재사용하고, 배경 그라데이션도 재사용합니다.
- 게임은 60회/초의 고정 시간 간격으로 진행하고 메뉴는 30회/초로 그립니다. 120Hz 화면에서도 필요 이상의 반복 작업을 하지 않습니다.
- 효과음 파형을 미리 만들고 최대 동시 재생 수를 제한합니다. 효과 파티클/떠오르는 글자 수에도 상한을 둡니다.
- 진행 저장을 한 묶음으로 합쳐 브라우저가 쉬는 시간에 기록하고, 앱을 떠날 때 미기록 데이터를 즉시 저장합니다. 이전 버전 저장 데이터도 읽습니다.
- 간택 순간 의도적으로 넣었던 0.07초 정지를 없앴습니다.
- **삼색이 / 턱시도 / 치즈냥**이 각각 다른 털 무늬로 등장합니다.
- 일반 **6단계부터 칸 자체가 좌우로 이동하며 간격도 변합니다.** 11단계 이후와 무한 모드에서는 움직임이 더 큽니다. 고양이, 동전, 플레이어 판정도 칸 좌표를 따라갑니다.

기기별 끊김이 모두 해소됐다는 의미는 아닙니다. 자동 검사는 실제 휴대폰 성능 측정을 대체하지 않습니다.

## 조작과 난도

`app/src/main/assets/index.html`을 브라우저로 열어 실행할 수도 있습니다. 외부 리소스나 서버 없이 동작하며 Android 앱에도 포함됩니다.

- 좌우 버튼 한 번 탭: 한 차선 이동. 게임 화면 좌우 스와이프도 지원합니다.
- PC: 방향키 또는 A/D 이동, Space 슬쩍 회피, Esc 일시 정지.
- 가운데 **슬쩍!**: 일반 0.42초 회피/대기시간 8초, 무한 0.32초 회피/대기시간 9초.
- 세 번 간택되면 해당 일반 단계 또는 무한 모드를 재도전합니다.
- 안전 차선은 연속으로 같게 나오지 않습니다. 2단계부터 매번 두 차선을 막고 6단계부터 반대편까지 두 번 탭해야 하는 패턴이 나옵니다.
- 고양이 기본 속도 1단계 220, 10단계 370, 11단계 410, 20단계 600. 등장 간격도 0.96초에서 0.38초로 점점 짧아집니다.
- 무한 모드는 속도 400/등장 간격 0.48초로 시작하고 20초마다 속도 +18/간격 -0.012초. 최대 속도 600/최소 간격 0.38초입니다.
- 화면 길이에 따라 보인 뒤 도달하는 시간이 달라지지 않도록 속도를 보정합니다.
- 근접 회피 보너스, 콤보, 점수 배수, 동전, 일반 단계별 별 기록이 있습니다.
- 진행도/별/최고 점수/최고 구간을 기기에 저장합니다. 앱을 떠나면 자동 일시 정지합니다.

## 이전 APK에서 업데이트

v0.2 APK는 임시 빌드 서명으로 만들어졌습니다. 새 APK 설치 시 서명이 달라 업데이트가 차단될 수 있으며, 이 경우 기존 앱을 삭제한 뒤 설치해야 합니다. 앱 삭제 시 기존 기록도 삭제됩니다. v0.3~0.4의 캐시 경로에서 서명 파일이 보존되지 않은 문제를 확인했습니다. v0.5부터 명시적인 테스트 서명 파일을 만들고 실제로 빌드에 사용하여 캐시에 보관합니다. 캐시가 삭제되면 서명이 바뀔 수 있습니다.

같은 앱 데이터가 보존되는 업데이트에서는 기존 10단계 완료 기록을 그대로 사용하므로 일반 11단계와 별도 무한 모드를 바로 선택할 수 있습니다.

## 검증 및 현재 상태

`node tests/game.test.cjs`로 캠페인 20단계, 무한 해금, 최고기록 복원, 충돌, 회피, 콤보, 생성 패턴을 검사합니다. GitHub Actions는 이 검사와 Android APK 컴파일을 수행합니다. 실제 Android 기기에서 터치감·화면 배치·소리·성능은 추가 확인이 필요합니다. 상용 게임과 동등한 품질로 검증된 상태는 아닙니다.

Android 6.0 이상을 대상으로 하며 인터넷 권한, 광고, 계정 또는 서버가 없습니다.
