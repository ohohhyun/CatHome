# 집사 사절! · 퇴근길 대작전

집으로 가는 길, 달려드는 고양이에게 집사로 간택되는 것을 피하는 세로형 모바일 아케이드 게임입니다. 10개 골목을 모두 완료하면 **무한 모드**가 해금됩니다.

## APK 받기

이 저장소의 **Actions → Build installable APK → 가장 최근 성공한 실행**을 엽니다. 아래쪽 **Artifacts → CatHome-APK**를 내려받아 압축을 풀면 `app-debug.apk`가 있습니다. GitHub 로그인이 필요합니다.

휴대폰에 APK를 옮겨 설치합니다. 설치한 파일 앱에 '알 수 없는 앱 설치' 허용이 필요할 수 있습니다. 테스트용 APK이며 Play 스토어 배포용 서명은 아닙니다.

## Android Studio에서 열기

1. 이 페이지의 초록색 **Code → Download ZIP**을 눌러 압축을 풉니다.
2. Android Studio의 **Open**으로 `settings.gradle` 파일과 `app` 폴더가 들어 있는 폴더를 엽니다.
3. **Trust Project**를 선택하고 Gradle Sync를 기다립니다. 처음에는 인터넷으로 도구를 받습니다.
4. SDK 설치가 필요하다고 나오면 Android SDK 35 설치를 허용합니다. Gradle JVM은 Android Studio의 내장 JDK 17 이상을 사용합니다.
5. **Build → Generate App Bundles or APKs → Generate APKs** 또는 버전에 따라 **Build APK(s)** 실행.
6. `app/build/outputs/apk/debug/app-debug.apk`가 생성됩니다.

Windows 터미널에서는 프로젝트 폴더에서 `gradlew.bat assembleDebug`를 실행할 수도 있습니다. 기본 Android Studio 설치 경로의 내장 Java를 사용하며, 다른 위치에 설치했다면 `JAVA_HOME`을 맞춰야 합니다.

## 모드 구성 · v0.9

시작 화면에 **일반 모드 / 무한 모드**가 큰 버튼 두 개로 표시됩니다.

- **일반 모드**: 총 30단계. 단계가 오를수록 속도와 고양이 등장 빈도가 증가하고 11~30단계는 더 어렵습니다. 30단계를 완료하면 귀가 엔딩입니다.
- **무한 모드**: 일반 모드 10단계를 완료하면 해금됩니다. 시작 화면의 별도 무한 모드 버튼으로 들어갑니다. 일반 11단계에 들어가도 자동으로 무한 모드로 바뀌지 않습니다.
- 일반 모드 10단계 이후에도 11~30단계를 계속 진행하거나, 시작 화면으로 돌아가 무한 모드를 선택할 수 있습니다.
- 무한 모드는 별도 점수/최고 구간 기록으로 끝없이 진행합니다. 20초마다 다음 구간으로 넘어갑니다. 실패하면 무한 1구간부터 재도전합니다.
- 무한 모드를 해도 일반 모드 완료 단계는 변하지 않습니다.

## 11단계 새 고양이 · v0.8

메인 문구는 **길냥이들의 집사 모집!** 입니다.

- **뚱냥이**: 배를 드러낸 통통한 몸으로 누워서 **붙어 있는 두 칸 사이를 좌우로 반복 왕복**합니다. 남은 세 번째 칸은 같은 줄의 다른 고양이가 막습니다. 바깥 칸에 계속 서서 피하는 방식이 아니라, 구르며 비워지는 두 칸 안쪽의 빈자리로 피해야 합니다. 금색 선으로 왕복 구간을 표시합니다.
- **깡패냥이**: 진한 눈썹과 붉은 목도리가 있는 고양이입니다. 제자리에서 위로 뜨는 모션과 달리 실제 화면에서 전방으로 도약한 뒤 착지합니다.
- 두 패턴은 일반 1~10단계와 무한 1~10탄에는 나오지 않고 **각 모드 11단계/11탄부터** 섞여 나옵니다. 21~30단계에서는 대각선/도약/페인트와 조합합니다.

## 무한 모드 51~100탄 · v0.8

무한 모드는 20초마다 다음 탄으로 이어집니다. 저장된 최고 도달 기록은 유지합니다.

| 탄 | 기본 속도 | 기본 등장 간격 | 구성 |
| --- | ---: | ---: | --- |
| 1~50 | 400~600 | 0.48~0.38초 | 기존 곡선 + 고양이 혼합 패턴 |
| 51 | 604.8 | 0.3772초 | 하드 리듬 시작 |
| 75 | 720 | 0.31초 | 짧은 연속 이동과 두 칸 이동 조합 |
| 100 | 840 | 0.24초 | 고수용 빠른 연속 회피 목표 |
| 101~200 이후 | 최대 900 | 최소 0.22초 | 추가 상승 후 상한 유지 |

51탄부터 8박 패턴으로 차선을 바꾸고, 짧고 긴 간격을 섞습니다. 100탄에서는 초당 약 네 줄의 고양이를 읽으며 한 칸/두 칸 이동을 이어가야 합니다. 이 구간은 조작 반응을 빠르게 하고 짧은 화면의 세로 판정을 보정해 피할 수 없는 조합을 줄였습니다.

고수 리듬 게임에 가까운 체감 난도를 목표로 조정한 것이며, 실제 사용자의 숙련도에 따른 난도 평가는 별개입니다.

## 상점과 코인

게임 시작 화면의 **아이템 상점**에서 게임에서 모은 코인으로 구매합니다. 게임 도중에는 구매할 수 없습니다. 화면에서 먹는 코인 1개가 지갑의 1코인이 되며, 점수와는 별개입니다. 실패해도 이미 먹은 코인은 남습니다.

| 아이템 | 가격 | 사용 |
| --- | --- | --- |
| 이어하기 | 24코인 | 간택 완료 화면에서 같은 시간/점수로 이어갑니다. 간택 횟수는 초기화되고 가까운 고양이들을 비웁니다. |
| 우산 타기 | 24코인 | 게임 중 아이템 버튼으로 사용. 2초 동안 공중으로 떠서 간택을 피합니다. |
| 물총 쏘기 | 24코인 | 게임 중 아이템 버튼으로 사용. 3초 동안 바라보는 앞쪽으로 물을 쏘며 맞은 고양이는 달아납니다. |
| 구운 생선 | 24코인 | 오른쪽 화면 밖으로 던집니다. 던진 순간 화면에 걸쳐 보이는 고양이만 오른쪽으로 따라 나가며 이후 고양이에는 효과가 없습니다. |

종류별 최대 **99개 보유**할 수 있고, 구매 수량을 1~99개로 정합니다. **한 판에 종류별 1개만 사용**할 수 있습니다. 일반 모드의 한 단계 도전 또는 무한 모드 한 번의 도전을 한 판으로 취급합니다. 이어하기는 같은 판을 계속하므로 우산/물총의 사용 제한이 초기화되지 않습니다. 다시 도전 또는 다음 단계에서 새 사용 횟수가 주어집니다.

일반 한 판에서 대략 8~12코인을 모으며, 아이템 가격을 24코인으로 올려 약 세 판에 한 종류 한 개를 살 수 있도록 코인 등장 빈도를 단계 길이에 맞춰 조정했습니다. 실제 수입은 플레이 시간과 코인을 얼마나 주웠는지에 따라 달라집니다. 현금 결제나 광고는 없습니다.

## 버튼과 소리

- 이동 버튼은 v0.6보다 **7.4px(버튼 높이의 약 10%)만 더 위로** 옮겼습니다. 최초 위치 대비 총 22.4px 상승했습니다.
- 탭/스와이프 안내는 상단 HUD로 옮기고, 캐릭터 아래의 중복 안내 문구를 제거했습니다.
- 소리 설정은 조작부에서 제거했습니다. 게임 중에는 위쪽 일시정지 → **소리 설정**에서 배경음/효과음을 따로 조절합니다. 시작 화면에는 설정 톱니가 있습니다.
- 직접 작곡/합성한 잔잔한 **16초 배경음**을 반복 재생합니다. APK 안에 OGG 파일을 포함하므로 인터넷이 필요 없습니다. 처음 시작 버튼을 누르면 재생됩니다.
- 앱을 벗어나면 음악을 멈추고 진행 데이터를 저장합니다.

## 21~30단계의 새 고양이

속도는 20단계의 600을 넘기지 않습니다. 대각선 점프, 공중 도약, 방향을 속였다 돌아오는 페인트와 교차 점프를 섞어 난도를 높입니다. 샴냥/회색냥/검은냥이 추가되고, 기존 삼색이/턱시도/치즈냥도 계속 나옵니다. 점프는 캐릭터에 닿기 전에 착지하며 도착 차선을 읽을 수 있는 화살표를 표시합니다.

v0.5의 그림 캐시, 고정 시간 간격, 갱신 제한, 효과음/파티클 수 제한, 지연 저장 최적화는 유지했습니다.

## 조작과 난도

`app/src/main/assets/index.html`을 브라우저로 열어 실행할 수도 있습니다. 외부 리소스나 서버 없이 동작하며 Android 앱에도 포함됩니다.

- 좌우 버튼 한 번 탭: 한 차선 이동. 게임 화면 좌우 스와이프도 지원합니다.
- PC: 방향키 또는 A/D 이동, Space 슬쩍 회피, Esc 일시 정지.
- 가운데 **슬쩍!**: 일반 0.42초 회피/대기시간 8초, 무한 0.32초 회피/대기시간 9초.
- 세 번 간택되면 해당 일반 단계 또는 무한 모드를 재도전합니다.
- 안전 차선은 연속으로 같게 나오지 않습니다. 2단계부터 매번 두 차선을 막고 6단계부터 반대편까지 두 번 탭해야 하는 패턴이 나옵니다.
- 고양이 기본 속도 1단계 220, 10단계 370, 11단계 410, 20~30단계 600. 등장 간격도 0.96초에서 0.38초로 점점 짧아집니다.
- 무한 모드의 속도/간격은 위의 51~100탄 곡선을 따릅니다. 100탄 이후에도 계속 진행하며 속도 900/간격 0.22초에서 상한을 둡니다.
- 화면 길이에 따라 보인 뒤 도달하는 시간이 달라지지 않도록 속도를 보정합니다.
- 근접 회피 보너스, 콤보, 점수 배수, 동전, 일반 단계별 별 기록이 있습니다.
- 진행도/별/최고 점수/최고 구간을 기기에 저장합니다. 앱을 떠나면 자동 일시 정지합니다.

## 이전 APK에서 업데이트

v0.2 APK는 임시 빌드 서명으로 만들어졌습니다. 새 APK 설치 시 서명이 달라 업데이트가 차단될 수 있으며, 이 경우 기존 앱을 삭제한 뒤 설치해야 합니다. 앱 삭제 시 기존 기록도 삭제됩니다. v0.3~0.4의 캐시 경로에서 서명 파일이 보존되지 않은 문제를 확인했습니다. v0.5부터 명시적인 테스트 서명 파일을 만들고 실제로 빌드에 사용하여 캐시에 보관합니다. 캐시가 삭제되면 서명이 바뀔 수 있습니다.

같은 앱 데이터가 보존되는 업데이트에서는 기존 10단계 완료 기록을 그대로 사용하므로 일반 11단계와 별도 무한 모드를 바로 선택할 수 있습니다.

## 검증 및 현재 상태

`node tests/game.test.cjs`로 캠페인 30단계, 무한 해금, 최고기록 복원, 충돌, 회피, 콤보, 생성 패턴을 검사합니다. GitHub Actions는 이 검사와 Android APK 컴파일을 수행합니다. 실제 Android 기기에서 터치감·화면 배치·소리·성능은 추가 확인이 필요합니다. 상용 게임과 동등한 품질로 검증된 상태는 아닙니다.

Android 6.0 이상을 대상으로 하며 인터넷 권한, 광고, 계정 또는 서버가 없습니다.

## v0.9 왕복 뚱냥이 패치

한 번 가로지르던 뚱냥이를 반복 왕복 패턴으로 수정했습니다. 한 묶음에 뚱냥이는 한 마리이며, 남은 칸을 막는 고양이도 정확히 한 마리입니다. 둘은 같은 세로 위치로 내려옵니다. 세로로 다가오는 동안 여러 번 방향을 바꾸고, 플레이어가 지나갈 때도 두 칸 중 피할 수 있는 자리가 남도록 궤적을 맞췄습니다. 물총/생선/우산 효과와 기존 24코인 가격 및 기록 저장을 유지합니다.
