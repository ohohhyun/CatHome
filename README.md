# ASHEN RIFT 2.0 · 잿빛 균열

CatHome Android 프로젝트의 **영구 성장형 횡스크롤 액션 RPG**입니다. 마을에서 의뢰와 장비를 정비하고, 던전을 탐험해 전리품을 모으고, 새로운 지역과 직업 능력을 해금한 뒤 만렙 원정으로 이어집니다. 짧은 원정이 끝나도 캐릭터·장비·퀘스트·숙련 기록이 유지됩니다.

## 별도로 설치하는 APK · 기존 게임 유지

**잿빛 균열은 별도 앱 `com.ashenrift.game`입니다. ‘집사 사절!’의 `com.cathome.game`을 대체하지 않습니다.** 두 게임을 함께 설치할 수 있습니다. GitHub main의 기존 게임도 변경하지 않았으며 새 게임은 전용 브랜치와 PR에 있습니다.

Actions → Build installable APK → codex/ashen-rift-apk의 최신 성공 실행에서:

- **AshenRift-Separate-APK**: `AshenRift-2.0.1-Separate.apk`. 새 게임을 별도로 설치합니다.
- **CatHome-Original-Restore-APK**: `CatHome-0.7-Restore.apk`. 이전에 잘못된 공유 앱 ID의 1.0/2.0 APK를 설치해 ‘집사 사절!’이 바뀐 경우 사용하는 기존 게임 복구 파일입니다. 해당 파일은 원본 게임과 같은 앱 ID·서명, 더 높은 설치 버전 번호를 사용합니다.

**이전에 제공한 AshenRift-1.0.apk / AshenRift-2.0.apk는 같은 com.cathome.game을 사용하므로 더 이상 설치하지 마세요.** 이미 설치한 경우 앱을 먼저 삭제하지 마세요. 기존 게임 데이터가 남아 있을 때 복구 APK를 업데이트 설치하면 원본 코드가 그 저장을 읽을 수 있습니다. 기기에서 이미 삭제했거나 데이터가 지워진 기록의 복구는 보장하지 않습니다.

분리된 새 앱은 Android의 다른 저장 공간을 사용하므로 이전 공유 ID의 잿빛 균열 저장을 자동으로 가져오지 않습니다. 새 앱 내부에서는 영구 저장과 저장 형식 이전을 계속 지원합니다. 다른 앱의 기록을 덮어쓰거나 읽지 않습니다.

새 게임 versionCode 10 / versionName 2.0.1-separate-app. 복구 파일은 보관된 CatHome v0.7 전체 소스에서 화면·로직·앱 ID를 유지하고 임시 빌드 사본의 versionCode만 10으로 올려 빌드합니다. 보관 소스와 main은 변경하지 않습니다. 원본은 `legacy/cathome-0.7/`에 있습니다.

Android 6.0 이상과 최신 Android System WebView를 권장합니다. GitHub Artifact 다운로드에는 로그인이 필요하며 파일 앱의 ‘알 수 없는 앱 설치’ 허용이 필요할 수 있습니다. 테스트 서명 APK이며 Play 스토어용 서명은 아닙니다.

## 계속 이어지는 플레이

1. **마을 · 재의 항구**: 원정대 의뢰, 원정 지도, 장비 가방, 전직·스킬, 제작·강화에 접근합니다.
2. **메인 의뢰와 지역 해금**: 8개 지역의 던전 24개를 순서대로 정복하고 보상을 보고해 다음 목적지를 엽니다. 의뢰 보상은 중복 수령할 수 없습니다.
3. **던전 탐색**: 일반 던전은 5개 방입니다. 각 방의 적을 정리하고 오른쪽 관문으로 직접 이동합니다. 마지막 방의 보스를 처치하면 정산합니다.
4. **장비 파밍과 빌드**: 직업별 장비를 모으고 착용·강화·분해·제작하며 스킬 포인트를 배분합니다. 같은 던전을 다시 돌아 재료와 더 좋은 장비를 얻을 수 있습니다.
5. **전직과 각성**: 20레벨·메인 의뢰 8개 완료로 전직, 45레벨·전직·메인 의뢰 17개 완료로 각성합니다. 직업명, 스킬, 포인트가 바뀝니다.
6. **60레벨 이후**: 메인 의뢰 24개를 마치면 균열·심연·보스 5연전이 열립니다. 최대 레벨에서도 경험치로 숙련을 계속 높이고, 에픽 세트와 높은 균열 기록을 노립니다.

입장 횟수나 피로도 제한이 없습니다. 일일 의뢰는 추가 보상이며 일반 플레이를 막지 않습니다. 원정에서 실패해도 기존 캐릭터 성장과 장비가 초기화되지 않습니다.

## 직업과 스킬

| 직업 | 역할 | 전직 / 각성 |
|---|---|---|
| 카엘 · 흑염 검사 | 대검, 근접 콤보, 흑염 범위 공격 | 재의 검성 / 흑일의 계승자 |
| 린 · 월광 창술사 | 장거리 찌르기, 빠른 돌진 | 월영의 무희 / 천월의 지배자 |
| 베인 · 강철 격투가 | 높은 체력, 보호막, 중량 공격 | 철혈의 투사 / 멸성의 심판자 |
| 세라 · 마탄 마도사 | 원거리 마법, 흡인, 동료 치유 | 공허의 사수 / 심연의 기록자 |

직업별 6개, 총 24개 전용 스킬이 있습니다. 습득 레벨은 1/5/10/15/20/45이며, 다섯 번째는 전직, 여섯 번째는 각성이 필요합니다. 기본 공격은 별도이며 세 번째 연속 공격이 강타입니다. 각성 스킬은 적중으로 모은 게이지 100%를 사용합니다.

레벨마다 SP를 얻으며 높은 단계 스킬은 더 많은 SP를 사용합니다. 모든 스킬을 최고 랭크로 만들 수 없도록 포인트 예산을 두었습니다. 마을에서 무료로 초기화하고 다른 빌드를 시험할 수 있습니다. 전직·각성 시 추가 포인트를 줍니다.

## 장비와 파밍

- 부위 6종: 무기 / 상의 / 하의 / 신발 / 목걸이 / 반지.
- 등급 5종: 일반 / 마법 / 희귀 / 유니크 / 에픽. 장비 레벨과 강화가 실제 공격력·생명력에 반영됩니다.
- 직업별 2/4/6세트 효과. 유니크 이상 장비를 모아 공격·생명·집중 보너스를 받습니다.
- 강화는 +15까지 확정 성공하며 실패·파괴·하락이 없습니다. 높은 단계일수록 골드·철편 비용이 증가합니다.
- 미착용 장비를 분해해 가루·철편·인장을 얻습니다. 착용·잠금 장비는 분해할 수 없으며, 유니크·에픽은 획득 시 자동 잠금됩니다.
- 원하는 부위의 유니크·에픽 세트를 재료로 확정 제작할 수 있습니다. 에픽 제작에는 60레벨과 보스 공방에서 얻는 핵이 필요합니다.
- 원정 40회 연속으로 에픽을 얻지 못하면 다음 원정에서 에픽을 보장합니다. 이 기록도 캐릭터별로 저장합니다.
- 가방은 캐릭터별 200칸이며 빈칸이 부족하면 입장을 막아 전리품 손실을 방지합니다.

## 만렙 콘텐츠

| 원정 | 진행과 보상 |
|---|---|
| 균열 | 3개 방, 정복 시 다음 층 해금. 단계별 적 능력 증가, 최고 기록과 숙련 성장. 최대 9,999층. |
| 심연의 틈 | 인장 3개로 입장하는 3개 방. 에픽 확률과 전리품 수 증가. |
| 종말의 공방 | 보스 5연전. 반복 정복마다 핵 2개, 주간 첫 정복에 핵 6개 추가. |

일일 의뢰는 던전 3회, 몬스터 100마리, 협동 원정 1회입니다. 일일·주간 기록은 휴대폰의 현지 날짜를 사용하며 중앙 서버 시간 검증은 없습니다.

## 싱글 · 파티 · 난이도 차등

| 인원 | 일반 난이도 보통 방 | 일반 몬스터 체력 | 보스 체력 | 보스 지원몹 | 개인 골드·경험치 |
|---|---|---|---|---|---|
| 1인 | 5~8 | 1.00배 | 1.00배 | 0 | 100% |
| 2인 | 7~10 | 1.25배 | 1.70배 | 2 | 108% |
| 3인 | 9~12 | 1.45배 | 2.40배 | 4 | 116% |
| 4인 | 11~14 | 1.65배 | 3.10배 | 6 | 124% + 추가 전리품 1개 |

일반/모험/왕의 길/악몽 난이도는 체력 1/1.45/2.1/3배를 별도로 적용합니다. 왕의 길은 보통 방에 2마리, 악몽은 4마리가 추가되며 보스 지원몹도 늘어납니다. 공격력·공격 간격·보상·상위 등급 확률도 함께 바뀝니다. 적은 담당 대상을 나누고 보스는 예고 공격 패턴을 순환합니다. 보스 방어 게이지를 깨면 짧은 추가 피해 기회가 열립니다.

인원이 줄면 현재 적 체력을 남은 비율대로 낮추고 과도한 지원몹을 정리하며, 다음 방도 남은 인원 기준으로 생성합니다. 숫자는 초기 조정값이며 장기간의 실제 플레이 밸런스 검증은 아직 필요합니다.

## 같은 Wi-Fi 협동

모두 같은 Wi-Fi와 같은 2.0 APK를 사용하세요. 각자 캐릭터를 선택한 뒤 한 명이 **Wi-Fi 협동 → 방 만들기**로 표시된 IP·4자리 코드를 알려주고, 나머지가 입력해 참가합니다. 최대 4명, PC·계정·외부 게임 서버 없이 동작합니다.

파티원 모두가 목적지의 퀘스트·레벨·가방·입장 재료 조건을 충족해야 합니다. 전투 후 **마을로 돌아가기**로 파티를 유지하며 각자 장비와 퀘스트를 정비하고 다음 원정을 시작할 수 있습니다. 방장만 목적지·시작·일시정지·재도전을 조절합니다. 진행 중인 원정에는 새로 합류할 수 없습니다.

게스트 Wi-Fi나 AP 격리 환경에서는 연결되지 않을 수 있습니다. 방장 앱을 닫거나 백그라운드로 보내면 방이 종료됩니다. VPN이 있으면 표시된 방장 IP를 Wi-Fi 상세 정보와 비교하세요. 이전 1.0 클라이언트와는 호환되지 않습니다.

## 저장과 구성

게임·아트·한글 폰트를 APK에 포함합니다. 게임은 Canvas/WebView, LAN은 Java TCP 포트 47655를 사용합니다. 외부 웹사이트를 불러오는 방식이 아닙니다. 로그인·광고·과금·CDN 요청이 없습니다.

성장은 WebView 저장소와 Android SharedPreferences에 이중으로 보관하며 시작 시 더 최신 저장본을 선택합니다. 정산 원정 ID로 중복 보상을 막고, 구매·제작·분해·강화 후 즉시 저장합니다. 저장 공간이 부족해 양쪽 모두 저장에 실패하면 해당 거래를 되돌립니다. 캐릭터 4명의 장비·스킬·의뢰·기록은 개별적으로 유지합니다. 온라인 계정·기기 간 클라우드 동기화·경매장·거래 서버는 포함하지 않습니다.

## 검증과 빌드

```sh
node tools/unpack-art.cjs
node tests/game.test.cjs
node tests/rpg.test.cjs
# JDK 17 이상:
mkdir -p build/lan-test
javac -d build/lan-test app/src/main/java/com/cathome/game/LanTransport.java tests/LanTransportTest.java
java -cp build/lan-test LanTransportTest
# Playwright와 Chrome:
node tests/browser.test.cjs
bash gradlew assembleDebug
```

GitHub Actions는 전투·RPG 거래·원시 TCP·4인 게임 흐름을 검사하고 APK를 빌드·서명 검증합니다. 브라우저 검사는 Android 브리지를 모사하며 실제 Wi-Fi 기기 테스트를 대체하지 않습니다. 실제 휴대폰의 설치·멀티터치·공유기 연결·장시간 발열·플레이 밸런스는 별도 검증이 필요합니다.

기존 게임의 고유 캐릭터·맵·명칭을 복제하지 않은 독자 세계입니다. 캐릭터는 고해상도 2D 아트의 변형과 공격 이펙트로 표현하며, 던전은 공통 배경을 색조·지역 설정·전투 구성으로 구분합니다. 상용 게임의 방대한 아트·프레임별 전신 애니메이션·모든 시스템을 구현한 상태로 주장하지 않습니다.

`art-source/*.b64`의 아트·폰트는 Gradle 빌드가 자동 복원합니다. Gradle 8.9 / AGP 8.7.3 / SDK 35 / min SDK 23을 사용합니다. 수정 범위는 ohohhyun/CatHome뿐입니다.
