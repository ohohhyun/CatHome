# ASHEN RIFT · 잿빛 균열

CatHome Android 프로젝트를 횡스크롤 던전 액션 게임으로 전환한 버전입니다. 앱 ID `com.cathome.game`와 기존 테스트 서명 캐시를 유지합니다. 다른 저장소나 서비스는 변경하지 않습니다.

## 설치용 APK

**Actions → Build installable APK → 이 브랜치의 최신 성공 실행 → Artifacts → CatHome-AshenRift-APK**를 다운로드하고 압축을 풀어 `AshenRift-1.0.apk`를 설치하세요. Android 6.0 이상, 최신 Android System WebView를 권장합니다. GitHub Artifact 다운로드에는 GitHub 로그인이 필요합니다.

테스트용으로 서명된 APK입니다. 파일 앱의 '알 수 없는 앱 설치' 허용이 필요할 수 있습니다. 기존 CatHome과 같은 앱 ID이므로 업데이트 설치 시 기존 고양이 게임이 이 게임으로 바뀝니다. APK 빌드는 기존 캐시의 서명을 사용하지만 캐시가 사라진 경우 서명이 달라질 수 있습니다. 서명이 달라 설치가 거부되면 기존 앱 삭제가 필요하며, 삭제하면 기기 기록도 삭제됩니다.

## 같은 Wi-Fi에서 휴대폰끼리 협동

1. 모든 휴대폰에 APK를 설치하고 같은 Wi-Fi에 연결합니다.
2. 각자 캐릭터를 선택합니다. 방장은 던전과 난이도도 선택합니다.
3. 방장이 **Wi-Fi 협동 → 방 만들기**를 누릅니다. 표시된 **방장 IP와 4자리 코드**를 친구에게 알려줍니다.
4. 참가자는 **Wi-Fi 협동**에서 이름, 방장 IP, 코드를 입력하고 **참가**를 누릅니다.
5. 방장이 **함께 원정 시작**을 누르면 모두 같은 전투에 입장합니다. 최대 4명, PC나 외부 게임 서버 없이 동작합니다.

인터넷이 없어도 같은 공유기 안에서 통신할 수 있습니다. 게스트 Wi-Fi, AP 격리, 회사·학교 Wi-Fi의 기기 간 통신 차단에서는 접속할 수 없습니다. 공유기에서 기기 간 통신을 허용하거나 일반 개인 Wi-Fi를 사용하세요. 방장 휴대폰이 서버이므로 방장 앱을 닫거나 백그라운드로 보내면 연결이 종료됩니다. 참가자가 나가면 남은 인원은 계속 진행합니다. 진행 중인 원정에는 새로 참가할 수 없으며, 방장만 시작·일시정지·재도전할 수 있습니다.

방장 IP는 네트워크 인터페이스에서 읽습니다. VPN이나 Wi-Fi와 모바일 데이터가 동시에 활성화된 일부 기기에서는 잘못된 주소가 표시될 수 있으므로 Wi-Fi 상세 정보의 IPv4 주소와 비교하세요. 자동 방 검색이나 인터넷 매칭은 포함하지 않습니다.

## 직업 4종 · 전용 스킬 24개

| 직업 | 특징 | 스킬 6종 |
|---|---|---|
| 카엘 · 흑염 검사 | 대검, 근접 콤보, 흑염 | 흑염참 / 승룡검 / 잔영 돌진 / 화염 폭풍 / 혈화의 맹세 / 종언·흑일 |
| 린 · 월광 창술사 | 긴 사거리, 빠른 기동 | 월광 찌르기 / 반월 베기 / 유성 낙하 / 빙월의 창 / 월영 장막 / 천월·성우 |
| 베인 · 강철 격투가 | 높은 체력, 중량 공격 | 철산고 / 분쇄권 / 대지 붕괴 / 중력 포효 / 불굴의 갑주 / 멸성·폭쇄 |
| 세라 · 마탄 마도사 | 원거리, 범위 마법, 동료 치유 | 공허 탄환 / 마력 폭발 / 차원 균열 / 연쇄 섬광 / 별빛 치유 / 심연·묵시록 |

기본 공격은 연속 사용 가능하고 세 번째 공격마다 강타가 발생합니다. 스킬마다 범위·마나·재사용 대기시간이 다릅니다. 스킬 5는 보호막/공격 강화 또는 동료 치유이며, 스킬 6은 적중으로 쌓이는 각성 게이지 100%를 사용합니다.

## 원정과 성장

- 던전 3곳: 잿빛 성역 / 침묵의 제철소 / 월식의 왕좌.
- 던전당 5개 구역. 마지막 구역에 보스가 등장합니다.
- 일반 / 숙련 / 악몽 3개 난이도. 인원수와 난이도에 맞춰 적 체력이 증가합니다.
- 기사·마도사·중갑병과 보스. 적 공격은 바닥의 붉은 예고 영역으로 표시됩니다. 보스는 광역·지정 위치·연속 영역 공격을 사용합니다.
- 다음 구역에서 체력·마나를 회복하고 쓰러진 동료를 부활시킵니다. 모두 쓰러지면 실패합니다.
- 원정 보상 골드·경험치, 직업별 최대 30레벨, 공격·생명·집중 강화 각 10단계.
- 성장 기록은 기기에 저장하며 계정이나 클라우드 저장은 없습니다. 기존 CatHome 기록과 별도 키를 사용합니다.

## 조작

모바일은 가로 화면의 왼쪽 조이스틱, 회피·점프, 오른쪽 공격·6개 스킬 버튼을 사용합니다. PC 미리보기는 WASD/방향키 이동, J 공격, Shift 회피, Space 점프, 1~6 스킬, Esc 일시정지입니다. Wi-Fi 협동은 Android APK의 네이티브 연결을 사용합니다.

## 구성과 검증

게임은 앱에 포함된 Canvas/WebView에서 실행하고 LAN은 Java TCP 소켓으로 통신합니다. 원격 웹사이트를 여는 앱이 아니며, 아트·코드·인터페이스가 APK에 포함됩니다. 외부 폰트, CDN, 광고, 로그인, 유료 SDK가 없습니다. 굵은 선과 강한 셀 명암을 사용한 독자적인 캐릭터와 배경입니다. 기존 게임 캐릭터나 리소스는 포함하지 않습니다.

방장은 60Hz 고정 간격으로 전투를 계산하고 초당 15회 상태를 전달합니다. 참가자는 입력을 초당 30회 전달하며 화면 위치를 보간합니다. TCP 포트는 `47655`, 4자리 방 코드 인증과 4인 제한, 입력 유효성 확인, 패킷·전송 큐·효과 수 제한을 적용합니다. 이 프로토타입은 신뢰하는 같은 LAN의 친구들과 사용하는 구성이며 인터넷 공개 서버용으로 설계되지 않았습니다.

검사:

```sh
node tools/unpack-art.cjs
node tests/game.test.cjs
mkdir -p build/lan-test
javac -d build/lan-test app/src/main/java/com/cathome/game/LanTransport.java tests/LanTransportTest.java
java -cp build/lan-test LanTransportTest
# Playwright 설치 및 Chrome이 있는 환경:
node tests/browser.test.cjs
bash gradlew assembleDebug
```

GitHub Actions에서 전투 검사, 실제 TCP 소켓 4인 통신 검사, 브라우저 4개 클라이언트의 게임 프로토콜 검사와 APK 빌드를 수행합니다. UI 검사는 LAN 브리지를 모사하며 실제 Android Wi-Fi 검사를 대체하지 않습니다. 실제 휴대폰의 앱 설치·화면 비율·멀티터치·발열·배터리·공유기별 연결 상태는 추가 기기 검증이 필요합니다.

현재 결과물은 플레이 가능한 프로토타입입니다. 캐릭터는 고해상도 2D 아트의 이동·기울기·점프 및 공격 이펙트로 표현하며 상용 격투 게임의 프레임별 전신 애니메이션, 방대한 콘텐츠 분량과 같은 수준으로 완성·검증된 상태는 아닙니다. 던전은 공통 성역 배경에 색조와 전투 구성을 달리합니다.

아트 원본은 `art-source/*.webp.b64`에 있으며 Gradle 빌드가 WebP 파일로 자동 복원해 APK에 포함합니다. 별도 웹 미리보기나 테스트 전에는 `node tools/unpack-art.cjs`를 한 번 실행하세요. 기존 `tests/performance.test.cjs`와 `tests/preview.cjs`는 이전 고양이 게임용 자료이며 새 게임 검사에는 사용하지 않습니다. Gradle 8.9 / Android Gradle Plugin 8.7.3 / compile·target SDK 35 / min SDK 23입니다.
