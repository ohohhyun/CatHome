# 무명의 왕관 (Nameless Crown)

안드로이드용 싱글플레이 2D 다크 판타지 RPG — 별도 Godot 프로젝트 작업 영역.

- **기존 CatHome 게임과 완전히 분리**: 무명의 왕관의 소스는 이 저장소의 `NamelessCrown/` 아래에만 배치합니다.
- **GROUND 저장소와 무관**: GROUND에는 일절 변경하지 않습니다.
- **현재 상태**: 전용 작업 브랜치 및 폴더 준비 단계. 게임 전체 소스/원화는 아직 GitHub에 업로드되지 않았고 APK도 아직 빌드되지 않았습니다.
- **사용 엔진**: Godot 4.7.x (Compatibility 렌더러)
- **예정 기능**: 기사·마법사·상인·암살자 분기, 일반/하드코어, 터치 조작, 저장/불러오기, 풀컬러 이벤트 원화.
- **품질 기준**: APK 빌드/실행 성공과 직업별 실제 플레이 타임 검증 전에는 최종 완성으로 표시하지 않습니다.

프로젝트 파일을 이 폴더에 올린 뒤, CatHome의 기존 Android Gradle 빌드에 영향을 주지 않는 **별도 Godot APK 워크플로**를 추가할 예정입니다.
