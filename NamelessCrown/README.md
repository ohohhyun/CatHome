# NamelessCrown / GitHub APK package
The **original v0.6 Godot project** is archived in 21 numbered, binary Git blobs here in `packed/`.
GitHub Actions recombines all parts, verifies SHA-256 `a2c454cbc6116da17cf34f0f13a5f6e188e5ce4477f64f62141577a8071cc6cc`, and extracts the real Godot project before compiling.
Branch is `nameless-crown-dev` only; the existing CatHome Android game's code and build workflow are not changed. Nothing is merged into `main`.
This is **not yet a verified 100%-complete game**: story length, runtime playtime and mobile usability remain to be tested after successful APK export.
